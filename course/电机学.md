# 电机学（发电侧版）· 归纳总结

> 本站定位：把《电机学》按发电侧需要压缩成"够用、好复习、能对接现场"的版本。发电侧真正天天打交道的就两样东西：**变压器**和**同步发电机**，本页把力气花在这两处；异步电机懂原理，直流电机略过。
> 配套教材：汤蕴璆《电机学（第5版）》，机械工业出版社
> 配套网课：华北电力大学（保定）《电机学》MOOC（中国大学MOOC）
> 学习顺序建议：先读本页归纳 → 再跟慕课看对应章节 → 最后做教材课后题检验。

---

## 一、课程定位与学习方法

电机学是"电路原理"之后第二门核心课：电路解决"静态的连接问题"，电机学解决"磁场与运动产生的能量转换问题"——发电厂里没有一台设备离开磁与电的转换。

发电侧的学习取舍（按现场使用频率）：

- **变压器 ★★★**：主变、厂变、CT/PT 天天见，继保整定里变压器等值电路是基本功；
- **同步发电机 ★★★**：发电机本体、励磁、并网、功角——发电侧最核心的"产品"；
- **异步电机 ★★**：厂用电动机（风机、水泵、磨煤机）都是它，懂原理、会看铭牌即可；
- **直流电机 ★**：现代已被变频调速替代，现场极少，略过（了解名词就行）。

学习方法：

1. **先抓住两条物理规律**：感应电动势（e = N·dΦ/dt）和电磁力（F = BIl）——电机学 90% 的内容是这两条在绕圈、运动、饱和下的展开；
2. **会画等值电路**：变压器、同步发电机都有"等效电路"，把磁场问题变成电路问题，算起来就是电路原理那套；
3. **公式能默写**：标 ★★★ 的必须默写（E=4.44fNΦ、n=60f/p、s=(n1−n)/n1、P=(mE0U/Xs)sinδ）；
4. **对号入座现场设备**：学一个概念就找对应设备（主变铭牌、励磁柜、并网操作票），记忆最牢。

重要度标记：★★★ 必须掌握｜★★ 重点（会算会用）｜★ 了解（知道概念即可）

## 三、模块详解

### 模块一 · 磁路与电磁基本规律 ★★

**一句话定位**：电机学的"物理地基"——电与磁怎么互相转换，全部从这里长出来。

**1. 磁路基本概念**
- 磁通 Φ（类似电流）、磁动势 F = N·i（类似电动势，N 为匝数）、磁阻 R_m（类似电阻）；
- 磁路欧姆定律：Φ = F / R_m——形式和电路欧姆定律一样，但磁阻是**非线性**的（铁芯饱和后磁阻猛增）。

**2. 铁磁材料与损耗**
- B-H 曲线（磁化曲线）：有饱和区——铁芯不能无限磁化；
- **铁损**：磁滞损耗 + 涡流损耗（铁芯发热的来源，用硅钢片叠成就是为了减小涡流）；
- **铜损**：绕组电阻损耗（I²R）。

**3. 两条核心规律 ★★★（电机学的"宪法"）**
- **电磁感应（发电原理）**：e = −N·dΦ/dt。正弦交变磁通下，感应电动势：
  **E ≈ 4.44·f·N·Φm**（变压器电动势公式，必默写；Φm 为磁通最大值）
- **电磁力（电动原理）**：F = B·I·l。载流导体在磁场中受力，方向用左手定则；发电机反过来，运动导体切割磁力线产生电动势（右手定则）。

**4. 易错点**：磁路欧姆定律形式虽像电路，但磁阻非线性、磁通不会"流走"（闭环），不能照搬电路的计算习惯。

**与工作的连接**：变压器铁芯嗡嗡响+发热 = 铁损；发电机靠转子磁场"切割"定子绕组发电——全是这两条规律。

### 模块二 · 变压器 ★★★（发电侧重点）

**一句话定位**：把电压变大变小、把阻抗折算来折算去——电厂里最普遍的设备（主变、厂变、CT/PT），也是继保计算的核心元件。

**1. 基本原理与变比**
- 一次绕组通交流 → 铁芯产生交变磁通 → 二次绕组感应电动势 → 变压；
- 变比：**k = N₁/N₂ = U₁/U₂**（空载时近似，U 为电压有效值）；
- 电流关系（负载时）：I₁/I₂ ≈ 1/k（能量守恒：U₁I₁ ≈ U₂I₂）。

**2. 理想变压器与阻抗折算 ★★★**
- U₁/U₂ = k，I₁/I₂ = 1/k；
- **阻抗折算：副边负载 Z 折算到原边为 k²·Z**——这就是电路原理模块七讲的"阻抗放大 k² 倍"，继保整定、短路计算里"统一基准"的根源。

**3. 实际变压器等值电路**
- = 理想变压器 + **励磁支路**（激磁阻抗 Z_m，反映铁芯耗能与励磁电流）+ **漏阻抗**（Z₁、Z₂′，反映漏磁和绕组电阻）；
- 用电路原理的戴维南/相量法就能解它——两门课在这里咬合。

**4. 参数测定（两个试验，必懂）**
| 试验 | 怎么做 | 求什么 |
|---|---|---|
| **空载试验** | 低压侧加额定电压，高压侧开路 | 励磁参数 Z_m、铁损（空载损耗≈铁损）、变比 |
| **短路试验** | 低压侧短路，高压侧加电压使电流达额定 | 短路阻抗 Z_k（漏阻抗）、铜损（短路损耗≈额定铜损） |

- 短路电压（阻抗电压）u_k：短路试验时高压侧电压与额定电压之比，铭牌上都印着（如 u_k = 10.5%）——并联运行、短路计算都要用它。

**5. 标幺值 ★★**
- 标幺值 = 实际值 / 基准值，无量纲；短路阻抗、励磁阻抗用标幺值表示后，不同容量变压器可直接比较；
- **这是继保课"归算到统一基准"的数学基础**。

**6. 运行特性**
- 电压变化率 ΔU：从空载到满载，副边电压下降的百分比；
- 效率：η = P₂/P₁；**当铜损 = 铁损时效率最高**（约 50%~60% 负载时）。

**7. 三相变压器与连接组别 ★★★**
- 高压侧 Y/Δ 接法、低压侧 Y/Δ 接法组合，用"钟表法"表示：**连接组别**；
- 常见：**Yy0**（高低压都星形，同相位）、**Yd11**（高压星形/低压三角形，低压超前30°）、**Dyn11**（配电常用，高压三角形/低压星形带中性线）；
- 连接组别决定线电压相位关系——并网、并列运行必须一致。

**8. 并列运行条件**：①变比相同（误差≤0.5%）②连接组别相同 ③短路电压相近（误差≤10%）——缺一条都会产生环流或负荷分配不均。

**9. 互感器（CT/PT）——现场铁规矩**
- **CT（电流互感器）：二次侧绝对不许开路！**（开路会感应出危险高压、烧设备）——校验/换表前必须先短接；
- **PT（电压互感器）：二次侧不许短路**（短路烧 PT）——二次侧有熔断器保护；
- CT/PT 的变比就是变压器原理：CT 把大电流变小电流（100A→5A/1A），PT 把高电压变低电压（110kV→100V）。

**10. 易错点**
- **励磁涌流**：变压器空载合闸瞬间，铁芯饱和导致电流可达额定 6~8 倍，几个周期内衰减——继保的"涌流闭锁"就是防它误动；
- CT 极性接反会导致差动保护误动作——现场接线必查极性。

**与后续课程的连接**：继电保护（变压器差动/瓦斯保护、CT/PT 接线）、发电厂电气（主变选型、接线）、电力系统分析（变压器等值电路参与潮流/短路）。

### 模块三 · 交流绕组与旋转磁场（共同理论）★★

**一句话定位**：异步电机和同步电机的公共基础——三相绕组通三相电流，就产生一个"旋转的磁场"，所有交流电机都是围绕它转。

**1. 旋转磁场的产生**
- 三相绕组在空间上互差 120° 电角度，通三相电流（时间上互差 120°）→ 合成磁场以恒定大小旋转；
- 转向由**相序**决定（换相序就反转）；
- 旋转速度（同步转速）★★★：**n₁ = 60f / p**（r/min；f 频率 Hz，p 极对数）。
  - 50Hz 电网：2 极（p=1）→ 3000 r/min；4 极（p=2）→ 1500 r/min；6 极（p=3）→ 1000 r/min。

**2. 电角度与机械角度**：一对极 = 360° 电角度；电角度 = 机械角度 × p。

**3. 感应电动势频率**：f = p·n/60——转子转多快、磁极对数多少，就感应出多大频率（同步发电机并网就是让这个频率 = 电网 50Hz）。

**与后续课程的连接**：转速 = 60f/p 是变频调速的依据；同步发电机"转速锁定频率"，异步电机"转速落后频率"——下一模块的核心。

### 模块四 · 异步电机（了解原理）★★

**一句话定位**：旋转磁场"拖"着转子转，但转得慢半拍——厂里风机、水泵、磨煤机全是它。

**1. 结构与工作原理**
- 定子：三相绕组（产生旋转磁场）；转子：笼型（鼠笼）或绕线型；
- 原理：旋转磁场切割转子导体 → 感应电流 → 转子受力转动；转子永远**追不上**旋转磁场。

**2. 转差率 ★★★（必默写）**
- **s = (n₁ − n)/n₁**，n₁ 同步转速，n 转子转速；
- 电动机状态 0 < s < 1；启动瞬间 s = 1，空载 s ≈ 0。

**3. 几个重要特性（记结论）**
- **启动电流大**：直接启动可达额定电流 5~7 倍，但启动转矩不大——所以大电动机要降压启动或变频启动；
- 启动方式：直接启动（小容量）、星三角/软启动（降压）、**变频启动**（现代主流，还顺带调速）；
- 调速：变频调速（改变 f → 改变 n₁ → 改变 n），效率高、平滑——这就是变频器的作用。

**4. 应用与现场**
- 厂用电动机的铭牌参数要会读：额定功率（kW）、额定电压、额定电流、转差率、绝缘等级；
- 常见故障概念：缺相运行（烧电机）、过载、堵转——对应热保护/过流保护。

**与后续课程的连接**：发电厂电气部分（厂用电接线、电动机保护）、电力电子（变频器）。

### 模块五 · 同步发电机 ★★★（发电侧核心，重点中的重点）

**一句话定位**：发电厂的心脏——机械能变电能，靠励磁建立磁场、靠功角送出有功、靠并网进入系统。调度员和运行人员天天在跟它打交道。

**1. 结构与分类**
- 定子（电枢）：三相绕组，发出电能；
- 转子（磁极）：由励磁电流建立主磁场；
- **隐极机**：汽轮发电机（高转速 3000 r/min，转子细长，气隙均匀）；
- **凸极机**：水轮发电机（低转速，转子大直径多磁极，气隙不均匀）。

**2. 空载运行**
- 励磁电流 I_f → 转子磁通 → 定子绕组感应空载电动势 E₀；
- 空载特性 E₀ = f(I_f)：饱和曲线——励磁加到一定程度，E₀ 不再线性上升（铁芯饱和）。

**3. 负载运行：电枢反应与同步电抗 ★★★**
- 负载电流在定子产生电枢磁场，反过来影响主磁场（交磁/去磁/增磁）——叫**电枢反应**；
- 综合效果用**同步电抗 X_s** 一个参数概括（隐极机），电压方程：
  **E₀ = U + j·I·X_s + I·R_a**（忽略电阻：E₀ ≈ U + j·I·X_s）
- 这就是继保/系统分析里发电机等值电路"内阻抗 jX_s"的来历（电流越大、功率因数越滞后，端电压越往下掉）。

**4. 功角特性 ★★★（发电机的"灵魂"公式）**
- 隐极机输出有功：**P = (m·E₀·U / X_s)·sinδ**
  （m 相数，E₀ 空载电动势，U 端电压，X_s 同步电抗，**δ 功角 = E₀ 与 U 的夹角**）
- 功角 δ 的物理意义：转子磁场超前于合成磁场的角度——相当于"用力推"的程度；
- **δ 增大 → 输出有功增大**；δ = 90° 时 P 最大（静态稳定极限）；
- **静态稳定判据：dP/dδ > 0**（运行在功角特性上升段才稳定）；稳定储备系数越大越稳。
- ⚠️ **易错：功角 δ ≠ 功率因数角 φ**——一个反映"同步"的拉紧程度，一个反映"负荷"的相位。

**5. 励磁调节与无功 ★★★（运行口诀）**
- **"有功看汽门，无功看励磁"**：
  - 有功：由原动机（汽机进汽量/水头）决定——调汽门，发多少有功；
  - 无功：由励磁电流 I_f 决定——增励磁发无功（过励，滞相），减励磁吸收无功（欠励，进相）；
- **V 形曲线**：一定有功下，I_f 从欠励到过励，定子电流先减小后增大，**cosφ=1 时 I_f 最小**；
- 励磁系统 = AVR（自动电压调节器）——这就是"电力系统自动化"课程励磁调节的实物。

**6. 并网（并列）条件 ★★★**
- 四条件：①电压大小相等 ②频率相等 ③相位一致 ④相序一致；
- 方法：
  - **准同期**（主流）：满足四条件瞬间合闸（灯光法/自动准同期装置）；
  - **自同期**：先合闸后加励磁（用于事故快速并网，有冲击）。
- 并列错误后果：非同期并列 = 巨大冲击电流 + 转子振荡，严重时损坏发电机——运行规程的"红线操作"。

**7. 并网后的调节**
- 增汽门 → 增有功（δ 增大，功角增大）；减汽门 → 减有功；
- 增励磁 → 增无功（进相变滞相）；减励磁 → 减无功，甚至进相运行（吸收无功）；
- 系统频率 = 全电网有功平衡的结果；机端电压 = 无功平衡的结果。

**8. 故障与异常工况（联系继保）**
- **失磁**：励磁消失 → 发电机转为异步运行、吸收大量无功 → 失磁保护动作跳闸；
- **失步/振荡**：功角越过 90° 甚至 180°，P 变为负/振荡 → 失步保护、振荡闭锁；
- **进相运行**：欠励运行，机端电压下降、定子端部发热，有深度限制；
- 呼应继保课：**功角摇摆就是功角 δ 在摆动**——距离保护振荡闭锁的原理基础。

**与后续课程的连接**：电力系统分析（同步电抗入潮流、静态稳定）、电力系统自动化（AVR、AGC/AVC、调速器）、继电保护（失磁/失步/振荡闭锁）、发电厂电气（发电机主接线）。

### 模块六 · 机电能量转换与其他电机（了解）★

- **机电能量转换原理**：磁场是电与机械能转换的"中介"（耦合场），能量守恒的宏观表达；
- **直流电机**（略过）：靠换向器实现直流→旋转磁场；现代被"变频器+异步机"取代，现场基本退役；
- **控制电机**（了解名词）：伺服、步进、测速发电机——自动化控制用；
- **永磁/单相/开关磁阻电机**（了解）：永磁同步（风电、电动汽车）、单相电机（家电）。

## 六、自测题（学完全部模块后做）

1. 50Hz 电网中，2 极和 4 极同步发电机的同步转速各是多少？
2. 变压器变比 k = 10，副边空载电压 400V，原边电压约为多少？副边接 4Ω 负载时从原边看等效阻抗多大？
3. 连接组别 "Dyn11" 的含义是什么？
4. 为什么 CT 二次侧绝对不允许开路？
5. 4 极异步电动机在 50Hz 电网运行，额定转差率 s = 0.04，转子转速是多少？
6. 隐极同步发电机的功角特性公式是什么？静态稳定极限在功角多大处？为什么"增励磁能发无功、增汽门能发有功"？
7. 准同期并列的四个条件是什么？并列错误会怎样？
8. 变压器做短路试验求什么参数？空载试验求什么参数？

### 答案

1. 2 极（p=1）：n₁ = 60×50/1 = **3000 r/min**；4 极（p=2）：**1500 r/min**
2. U₁ ≈ k·U₂ = **4000V**；等效阻抗 Z' = k²·Z = 100×4 = **400Ω**
3. 高压侧三角形连接（D）、低压侧星形带中性线（yn）、低压线电压超前高压 30°（钟表11点位置）
4. CT 二次开路时，一次大电流全部变为励磁，二次感应出危险高压，可能击穿绝缘、危及人身与设备；因此校验前必须先短接二次
5. n₁ = 1500 r/min，n = (1−s)·n₁ = 0.96×1500 = **1440 r/min**
6. P = (m·E₀·U/X_s)·sinδ；静态稳定极限 **δ = 90°**（此点之后 dP/dδ < 0 失稳）。励磁改变 E₀ → 改变无功；汽门改变原动机输入功率 → 改变 δ 和 P
7. ①电压大小相等 ②频率相等 ③相位一致 ④相序一致。非同期并列会产生巨大冲击电流和转矩，可能损坏发电机与系统设备
8. 短路试验求**短路阻抗 Z_k（漏阻抗）与铜损**；空载试验求**励磁参数 Z_m 与铁损**（并测变比）
