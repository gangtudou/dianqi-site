## 一、课程定位与学习方法

速成八课解决的是"**是什么**"（每个保护怎么发现故障、四性怎么平衡），本页解决"**算多少**"（定值怎么定、灵敏度怎么校）。整定计算的完整链条：

```
短路电流计算（系统分析） → 整定原则（躲什么/校什么） → 各保护定值 → 灵敏度校验 → 定值单
        ↑ 标幺值/归算/对称分量（继保第0课 + 系统分析模块二）
```

学习方法：

1. **每个保护都按"躲什么、配谁、校什么"三问整定**——躲（定值高过什么）、配（和上下级怎么错开）、校（最不利情况下还灵不灵敏）；
2. **整定按最大运行方式算（防误动），灵敏度按最小运行方式校（防拒动）**——这条铁律贯穿全页；
3. **公式能默写**：Ⅰ段 I_op=K_rel·I_k.max、Ⅱ段配合公式、Ⅲ段 K_rel·K_ms/K_re、K_sen 校验式；
4. **对照现场定值单**：学完每个模块，拿单位保护定值单找对应项。

重要度标记：★★★ 必须掌握｜★★ 重点｜★ 了解

## 三、模块详解

### 模块一 · 整定的上游：短路电流与故障指纹 ★★★

**一句话定位**：定值的每个数字都从短路电流算出来——先会算故障电流，再谈整定。

**1. 四种短路电流的序网表达式（回顾 + 定量）**
| 故障类型 | 序网连接 | 短路电流 | 与三相短路关系 |
|---|---|---|---|
| 三相短路 | 只有正序 | I″ = E/X_Σ1 | 基准（最大） |
| 两相短路 | 正+负序串联 | I″ = √3·E/(X_Σ1+X_Σ2) | 当 X2=X1 时 = **0.866×三相**（你已默写的 0.866 的完整来历） |
| 单相接地 | 三序串联 | I″ = 3E/(X_Σ1+X_Σ2+X_Σ0) | 与 X0 大小有关，通常 < 三相 |
| 两相接地 | 三序并联 | — | 介于之间 |

- 工程简化：两相短路 = 0.866×三相（X2≈X1 时成立）；单相接地电流 = **3×İ₀**（零序电流的 3 倍）；
- **整定基准**：电流保护用三相短路算躲、用两相短路算灵敏度（最小方式）。

**2. 故障指纹 → 保护映射（速成第0课的"指纹"定量化）**
| 序分量 | 出现条件 | 对应保护 |
|---|---|---|
| 正序 | 一切正常与故障 | 距离保护、过流保护（测量基础） |
| 负序 | 不对称短路 | 负序电流/电压保护、复合电压闭锁 |
| 零序 | 接地故障（有接地通路） | 零序电流保护、零序方向 |

**3. 运行方式与整定铁律 ★★★**
- **最大运行方式**：系统阻抗最小 → 短路电流最大 → 整定按它算（定值要躲过最大电流）；
- **最小运行方式**：系统阻抗最大 → 短路电流最小 → 灵敏度按它校（最小故障也要能跳）；
- 一句话：**"整定往大躲，校验往小看"**。

**与现场的联系**：定值单上每个定值旁边都写着"按最大方式/最小方式"，这就是原因。

### 模块二 · 三段式电流保护整定全流程（完整例题）★★★

**一句话定位**：把速成课的"三个哨兵"用数字算一遍——本模块带你走完一整道完整整定题。

**例题**：110kV 单回线路，本线 L=30km（z1=0.4Ω/km，X_L=12Ω），相邻线路 40km（X=16Ω）。系统等值阻抗（归算到 110kV 侧，相电势取 E=63.5kV）：最大方式 Xs.min=1Ω，最小方式 Xs.max=3Ω。线路最大负荷电流 I_load.max = 400A。

**第1步：算短路电流（工具）**
- 本线末端最大方式三相短路：I_k.max = E/(Xs.min+X_L) = 63.5/13 = **4.88kA**
- 本线末端最小方式两相短路（灵敏度用）：I_k.min = 0.866×[E/(Xs.max+X_L)] = 0.866×(63.5/15) = 0.866×4.23 = **3.66kA**
- 相邻线路末端最大三相短路：I_k.max(邻) = 63.5/(1+12+16) = **2.19kA**

**第2步：Ⅰ段（躲本线末端最大短路）**
- I_op1 = K_rel×I_k.max = **1.3×4.88 = 6.35kA**，时限 **0s**；
- 保护范围校验（最小方式反解）：63.5/(3+0.4l) = 6.35 → l = **17.5km ≈ 58%**（最大方式 75%）——范围在 58%~75% 之间波动，这就是必须有Ⅱ段的原因。

**第3步：Ⅱ段（与相邻Ⅰ段配合）**
- 相邻Ⅰ段：I_op(邻1) = 1.3×2.19 = 2.85kA；
- 本Ⅱ段：I_op2 = **K_rel(≈1.1)×2.85 = 3.13kA**，时限 **+0.5s**；
- 灵敏度校验（本线末端最小方式）：K_sen = I_k.min/I_op2 = **3.66/3.13 = 1.35 ≥ 1.25 ✓**（合格；不够时改与邻线Ⅱ段配合，或降低配合系数）。

**第4步：Ⅲ段（躲最大负荷电流）**
- I_op3 = (K_rel·K_ms/K_re)×I_load.max = **(1.2×1.5/0.85)×400 = 847A ≈ 850A**，时限阶梯（本侧 **1.0s**）；
- 灵敏度校验：K_sen = 3.66kA/0.85kA = **4.3 ≥ 1.5 ✓**（近后备）；远后备（邻线末端最小）也校一遍。

**整定结果汇总**：
| 段 | 定值 | 时限 | 校验 |
|---|---|---|---|
| Ⅰ | 6.35kA | 0s | 范围 58%~75% ✓ |
| Ⅱ | 3.13kA | 0.5s | K_sen=1.35 ✓ |
| Ⅲ | 850A | 1.0s | K_sen=4.3 ✓ |

**易错点**：Ⅰ段躲"最大方式末端三相短路"不是末端两相；Ⅱ段灵敏度用"最小方式本线末端"；Ⅲ段 K_ms/K_re 千万别漏。

**与现场的联系**：这就是你单位过流保护定值单上的数字怎么来的——照着算一遍就通。

### 模块三 · 距离保护整定（阻抗平面）★★★

**一句话定位**：把电流换成阻抗当尺子——Ⅰ段躲过渡电阻、Ⅱ段配邻线、Ⅲ段躲负荷，全部在阻抗平面上看。

**1. 阻抗平面三个"门槛"**
- Ⅰ段：Z_op1 = (0.8~0.85)×Z_AB（**躲过渡电阻**：弧光电阻让测量阻抗偏大，定值打折）；
- Ⅱ段：Z_op2 = K_rel×(Z_AB + K_b×Z_BC)（K_b 分支系数：邻线短路时本侧感受的助增/外汲），时限 +0.5s；
- Ⅲ段：躲最小负荷阻抗：Z_load.min = U_min/(√3·I_load.max)，Z_op3 ≤ Z_load.min/(K_rel·K_ms·K_re·cos(φ_set−φ_load))——**负荷是几百欧、故障是几欧，天然隔得远远的**（速成第4课碾压电流保护的优势）。

**2. 例题（接模块二线路）**
- Ⅰ段：Z_op1 = 0.8×12 = **9.6Ω**，0s；
- Ⅱ段：Z_op2 = 0.8×(12+16) = **22.4Ω**（简化取 K_b=1），0.5s；灵敏度 K_sen = 22.4/12 = **1.87 ≥ 1.5 ✓**；
- Ⅲ段：Z_load.min = 0.9×110/(√3×0.4) ≈ **142.9Ω**；Z_op3 ≈ 142.9/1.5 ≈ **95Ω**（整定圆在负荷圆之外）。

**3. 振荡闭锁与断线闭锁（联系功角特性）**
- 系统振荡时测量阻抗沿"功角摇摆"轨迹缓慢扫进圆内——**变化慢 = 振荡 → 闭锁**；故障时阻抗突变——**变化快 = 故障 → 立即动作**（速成第4课功角摇摆 P=P_max·sinδ 在这里变成"阻抗轨迹"）；
- TV 断线：电压骤降像假故障但电流没变 → 断线闭锁，发告警。

**易错点**：Ⅰ段打折是为过渡电阻不是为运行方式；分支系数 K_b 忘算会高估保护范围。

**与现场的联系**：距离保护定值单上是欧姆不是安培——你单位线路保护屏里"测量阻抗圆"就是这张图。

### 模块四 · 零序保护整定（接地短路计算）★★

**一句话定位**：接地故障专用猎手——整定的核心是算零序短路电流（系统分析模块八的序网直接用上）。

**1. 单相接地短路电流计算 ★★**
- 单相接地：I_k(1) = 3E/(X_Σ1+X_Σ2+X_Σ0)；零序电流 İ₀ = E/(X_Σ1+X_Σ2+X_Σ0)；
- **单相接地电流 = 3×零序电流**（速成第5课"故障相电流=3倍序分量"的定量版）；
- 线路零序电抗约是正序的 **3 倍**（X0 ≈ 3X1），变压器零序阻抗由连接组别决定（Y 不接地无零序通路、YN 有、△ 绕组内循环）——所以零序网络与接地方式强绑定。

**2. 零序三段整定（接电流保护框架）**
- 零序Ⅰ段：躲本线末端单相接地最大零序电流（×1.2~1.3），0s；
- 零序Ⅱ段：与相邻零序Ⅰ段配合（×1.1），+0.5s，校灵敏度；
- 零序Ⅲ段：躲最大不平衡电流（CT 误差产生，约 1~2A——速成第5课"三相磁场抵消剩的残茬"），作为接地后备；
- **方向元件**：只认"母线→线路"方向（非故障线路零序是反方向回程——速成第5课最反直觉的点），配零序功率方向。

**3. 与小电流接地系统的对比（系统分析模块一闭环）**
- 110kV 及以上（直接接地）：零序电流数千安 → 零序保护主力；
- 10/35kV（不接地/消弧线圈）：接地电流几安~几十安 → 不用零序保护，用**绝缘监察（开口三角形）+ 选线 + 消弧线圈**三板斧。

**易错点**：零序Ⅰ段躲的是"最大零序电流"不是最大相电流；方向元件反装 = 非故障线路全误动。

**与现场的联系**：你单位 110kV 出线的零序定值单 + 10kV 母线绝缘监察装置，就是本模块两张脸。

### 模块五 · 变压器与母线差动深化（定量）★★

**一句话定位**：速成课讲了差动的"思想"（盒子理论、比率制动、二次谐波），这里补"定量的数"。

**1. 变压器差动整定三件事**
- **躲励磁涌流**：涌流可达额定 6~8 倍、只流电源侧，"长得像"内部故障 → **二次谐波制动：二次谐波占比 ≥ 15%~20% 闭锁**（涌流 30%~60%，真故障 <10%）——速成第7课头号敌人的定量判据；
- **躲不平衡电流**：CT 变比误差 + 有载调压分接头变化 → 差动启动值取 (0.2~0.3)×I_N 或按最大不平衡电流 ×K_rel；
- **躲区外故障不平衡**：用**比率制动**——差流/制动电流 > 0.5 才动作（速成第8课 K=0.5 的出处）。

**2. 比率制动的定量理解**
- 外部故障：差流只是 CT 误差残茬、占总电流比例极小 → K < 0.5 不动作；
- 内部故障：差流就是全部故障电流 → K 远大于 0.5 → 动作；
- **"不看偷了多少钱，看偷的钱占账面总额的比例"**——速成第8课那句话的数学表达。

**3. 母线差动**：全支路求和 + 比率制动 + **TA 断线闭锁**（CT 断线"算成"差流 → 立即闭锁并发告警——速成第8课最重要的辅助逻辑）。

**易错点**：涌流闭锁看二次谐波占比不是看幅值；比率制动系数不是差动启动值，两个概念别混。

**与现场的联系**：主变保护屏上"差动启动值""比率制动系数""二次谐波闭锁值"三张定值就是这里算的。

### 模块六 · 整定计算工具箱（全链总结）★★★

**一句话定位**：把五条线收成一张流程图——今后任何保护的整定都走这条链。

**1. 整定计算五步链 ★★★**
```
① 标幺值归算（统一基准）→ ② 画等值电路算短路电流（最大/最小方式）
→ ③ 按"躲什么"定定值（K_rel/K_ms/K_re）→ ④ 按"配谁"校配合（×1.1、+Δt）
→ ⑤ 按"最小方式"校灵敏度（K_sen ≥ 1.2~1.5）
```
- 每个保护只是第③步的"躲"的对象不同：电流保护躲最大短路电流、距离保护躲过渡电阻/负荷阻抗、零序保护躲最大零序/不平衡电流、差动躲涌流/不平衡电流。

**2. 四大系数速查（速成第3课的定量版）**
| 系数 | 作用 | 典型值 | 何时大 |
|---|---|---|---|
| K_rel | 防误动 | 1.15~1.3 | 躲的东西越算不准越大 |
| K_ms | 防误动（自启动冲击） | 1.5~3 | 带大电动机负荷时 |
| K_re | 防"返不回来" | 0.85~0.95 | 触点特性差的继电器 |
| K_sen | 防拒动（校验用） | ≥1.2~1.5 | 越兜底（后备）要求越高 |

**3. 看定值单的逐项对照**
- 定值单上的"动作电流/阻抗/时限/灵敏度"每一格，都能在五步链里找到出处；看不懂的项 = 好问题，记下来问。

**与现场的联系**：深化目标达成标准——**能独立算一段电流保护定值、能校灵敏度、能看懂定值单每一格**。

## 六、自测题（学完全部模块后做）

1. 模块二例题中，若最小方式系统阻抗从 3Ω 变成 6Ω，Ⅱ段灵敏度 K_sen 变为多少？还合格吗？（提示：先重算本线末端最小短路电流）
2. 距离保护Ⅰ段为什么取 0.8~0.85 倍而不是 1.0 倍线路阻抗？
3. 零序Ⅰ段躲的是什么电流？为什么单相接地电流 = 3×零序电流？
4. 变压器差动为什么要看"二次谐波占比"而不是只看电流幅值？
5. 整定计算五步链是哪五步？"整定往大躲、校验往小看"具体指什么？

### 答案

1. I_k.min = 0.866×[63.5/(6+12)] = 0.866×3.53 = **3.06kA**；K_sen = 3.06/3.13 = **0.98 < 1.25，不合格**——这正是"最小方式下灵敏度不足"的典型：需改与邻线Ⅱ段配合或降低配合系数（也可缩小Ⅱ段范围）
2. Ⅰ段要**躲过渡电阻**（弧光电阻使测量阻抗偏大）且留有可靠系数余量；取 1.0 倍会在末端附近发生"超越"（保护范围越过本线）
3. 零序Ⅰ段躲**本线末端最大单相接地零序电流**；单相接地时三序串联，故障相电流等于三倍零序分量（İa=İ₀+İ₁+İ₂，接地故障下故障相序分量相同）
4. 励磁涌流幅值很大（6~8倍额定）"长得像"内部故障，但它是**尖顶波、二次谐波含量 30%~60%**，而真故障的二次谐波 <10%——**看波形特征比看幅值可靠**（谐波闭锁）
5. ①标幺值归算 ②算短路电流（最大/最小方式）③按"躲什么"定定值 ④按"配谁"校配合（×1.1/+Δt）⑤按"最小方式"校灵敏度（K_sen≥1.2~1.5）；"整定往大躲"=定值按最大方式的最大故障量算（防误动），"校验往小看"=灵敏度按最小方式的最小故障量校（防拒动）
