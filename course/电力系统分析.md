## 一、课程定位与学习方法

前面两门课解决了"元件"问题：电路原理教你算电路，电机学教你发电机和变压器。**电力系统分析把几十上百台发电机、成千上万条线路、海量负荷拼成一张大网，回答三个运行问题：**

1. **潮流**：电从哪来、流到哪去、各节点电压多少？（稳态核心）
2. **电压与无功**：电压低/高了怎么调？（无功功率平衡决定电压）
3. **频率与有功**：频率偏离 50Hz 了怎么办？（有功功率平衡决定频率）
4. **短路**：电网发生短路时电流多大？（继保整定、设备校验的基础）

发电侧学习取舍：

- **潮流计算 ★★★**：会算辐射网/简单环网的电压功率分布——看懂调度台潮流画面的数学底子；
- **无功与电压调整 ★★★**：发电机励磁、变压器分接头、无功补偿——发电厂调压的直接手段；
- **有功与频率调整 ★★★**：一次调频/二次调频（AGC）——发电机调速器的上位概念；
- **短路计算基础 ★★★**：三相短路实用计算——继保整定和电气设备校验的公共语言；
- **计算机潮流算法 ★★**：了解牛顿法/PQ分解的思路即可；
- **暂态稳定、复杂不对称故障 ★**：了解概念，深度留给继保深化。

学习方法：

1. **先建"网"的概念**：一张系统图 = 节点（母线）+ 支路（线路/变压器）+ 注入（发电机/负荷），所有计算都是在这张网上做"功率和电压的平衡"；
2. **标幺值是通行货币**：全网计算统一基准，继保课第0课你已学过，这里把它变成日常工具；
3. **公式能默写**：标 ★★★ 的必默写（电压降落、标幺值换算、频率偏差公式、短路电流公式）；
4. **对照调度日常**：电压合格率、频率偏差、负荷预测、AGC——你在现场听到的调度术语全是这门课的概念。

重要度标记：★★★ 必须掌握｜★★ 重点（会算会用）｜★ 了解（知道概念即可）

## 三、模块详解

### 模块一 · 电力系统基本概念 ★★

**一句话定位**：先认识"网"长什么样——电压等级、接地方式、接线方式，是理解一切调度术语的门槛。

**1. 系统构成**：发电（发电机+升压变）→ 输电（高压线路）→ 变电（降压变）→ 配电 → 负荷。

**2. 电压等级（标称电压）**：3、6、10、35、110、220、500（750/1000）kV。
- 记忆：**35kV 以下算配电，110/220kV 算高压输电，500kV 及以上算超/特高压**；
- 发电厂出口：发电机电压（6.3/10.5/13.8/20kV）→ 升压到 110/220/500kV 并网送出。

**3. 中性点接地方式 ★★（和继保强相关）**
| 电压等级 | 接地方式 | 为什么 |
|---|---|---|
| 110kV 及以上 | **直接接地**（大电流接地） | 绝缘成本考虑：单相接地时故障电流大、但过电压低，靠继保快速跳闸 |
| 3~35kV | 不接地 / 经消弧线圈接地（小电流接地） | 单相接地可继续运行 2h（故障电流小），靠绝缘监察/选线装置处理 |
| 380/220V | 直接接地 | 人身安全（TN 系统） |

- 联系继保：**大电流接地系统才有零序电流保护（你已学的第5课零序保护）**，接地方式决定保护配置。

**4. 接线方式**：放射式、链式、环形（闭环结构开环运行）、双回线（重要用户）。**N-1 原则**：任一元件退出后系统仍能安全运行——电网设计的基本准则。

**与后续课程的连接**：接地方式→继保（零序/选线）、发电厂电气（厂用电接线）；N-1→调度运行。

### 模块二 · 元件等值电路与参数（标幺值）★★★

**一句话定位**：把发电机、变压器、线路都变成"电抗盒子"，全网用标幺值统一——这是所有计算的第一步。

**1. 发电机等值**：等值电动势 E′ + 次暂态电抗 X″d（短路计算用）或同步电抗 X_s（稳态用）——**电机学模块五的同步电抗在这里直接登场**。

**2. 变压器等值**：漏阻抗（由短路电压 u_k 换算）+ 励磁支路。电抗标幺值换算：
**X* = (u_k/100) × (S_B / S_N)**（u_k 百分数，S_B 基准容量，S_N 变压器额定容量）
- 例：50MVA 变压器 u_k=10.5%，基准 100MVA → x* = 0.105 × 100/50 = **0.21**（比发电机、线路大得多——变压器是短路电流的"拦路虎"）。

**3. 线路等值**：集中参数 R、X（每公里 r、x 乘以长度），电抗典型值 **x ≈ 0.4 Ω/km**（呼应用户继保课的困惑：0.4Ω/km 就是这么来的，架空线普遍取值）。
- 例：220kV 线路 20km → X = 0.4×20 = **8Ω**；基准 100MVA/220kV（Z_B = U_B²/S_B = 220²/100 = **484Ω**）→ x* = 8/484 ≈ **0.0165**。
- 对比：线路电抗标幺值比变压器小一个量级——所以短路电流在线路上几乎"畅通无阻"。

**4. 标幺值换算（必会）★**
- 基准值三件套：S_B、U_B（一般取各级平均额定电压 230/115/37/10.5/6.3kV）、Z_B = U_B²/S_B；
- 换算公式：**x*_new = x*_old × (S_B新/S_B旧) × (U_B旧/U_B新)²**；
- 全网统一基准后，不同电压等级的阻抗直接相加——继保第0课"归算到统一基准"的完整版。

**5. 易错点**：换基准时漏掉电压平方项、电压基准不取平均额定电压（要用 230/115 而不是 220/110）。

**与后续课程的连接**：短路计算、继保整定（归算）、潮流计算全部从这里出发。

### 模块三 · 潮流计算基础（手算）★★★

**一句话定位**：给定发电出力和负荷，算出每条线路的功率和每个节点电压——"电网的资产负债表"。

**1. 基本概念**
- 节点注入：发电机注入 P、负荷消耗 P，注入之和 = 网络损耗；
- 已知量：发电机出力、负荷功率、首端电压；待求：各支路功率、各节点电压；
- 手算前提：电压基本在额定附近（±10%内），可作近似。

**2. 电压降落与功率损耗（两个必用公式）★**
- 一条线路送端到受端，忽略横分量时纵向压降：
  **ΔU ≈ (P·R + Q·X) / U**
  （P、Q 为该支路流过的有功无功，R、X 线路阻抗，U 电压）
- 线路/变压器功率损耗：**ΔS ≈ (P² + Q²)·Z / U²**（电流平方×阻抗的功率形式）；
- 记忆：**"有功压电阻，无功压电抗"**——无功是电压的主要负担。

**3. 开式（辐射）网络手算步骤 ★★★**
1. 从末端开始，用负荷功率逐段累加，算出各支路的 P、Q；
2. 从首端开始，用 ΔU ≈ (PR+QX)/U 逐段算电压降落，得各节点电压；
3. 迭代 1~2 次修正（用算出的新电压重算损耗），手算一次足够。
- 例：末端负荷 10MW、cosφ=0.8（Q=7.5Mvar），线路 R=3Ω、X=12Ω，末端电压 110kV：
  ΔU ≈ (10×3 + 7.5×12)/110 = (30+90)/110 ≈ **1.09kV**，首端电压 ≈ **111.1kV**。
- 结论：线路长了、负载重了，末端电压就往下掉——这就是"为什么远距离输电要升压、要无功补偿"。

**4. 简单闭式（环网）网络**：功率按阻抗反比分配（均一网络按长度反比）——了解即可，工程上靠计算机算。

**5. 易错点**：ΔU 公式里的 P、Q 是该支路自身的，不是总负荷；功率单位要统一（MW/Mvar/kV）。

**与后续课程的连接**：电压合格率、线损率、经济运行——调度日常；也是理解"无功分层分区平衡"的前提。

### 模块四 · 计算机潮流算法（了解）★

**一句话定位**：大电网几百上千节点，手算不可能——计算机怎么算潮流。

- **节点方程**：每个节点列"功率平衡方程"（注入功率 = 流出功率），电路原理模块三的节点电压法的放大版；
- **牛顿-拉夫逊法**：迭代求解非线性方程组——先给初值，每次用"偏差"修正，收敛到解；
- **PQ分解法**：利用有功-功角、无功-电压的近似解耦，大幅加快计算（我国电网调度主流用此法）；
- 了解三件事即可：①潮流是"求全网功率电压平衡" ②迭代求解 ③有功无功可以分开看（对应后面的调频调压）。

**与后续课程的连接**：调度自动化 SCADA/EMS 里的状态估计、在线潮流。

### 模块五 · 无功功率与电压调整 ★★★

**一句话定位**：电压是"无功劳"——无功发多了电压偏高，少了电压偏低；调压的本质是调无功。

**1. 核心机理**
- 传输无功会在电抗上产生压降（模块三：ΔU≈QX/U）——**无功从高电压流向低电压**；
- 全系统电压水平由**无功功率平衡**决定：无功充足→电压高，无功不足→电压低（"电压是系统无功功率平衡的表现"）。

**2. 无功电源与调压手段 ★★★**
| 手段 | 原理 | 发电厂里的对应 |
|---|---|---|
| **发电机调压** | 调励磁（AVR）改变无功输出 | 电机学"无功看励磁"——最直接、最快 |
| **变压器分接头调压** | 改变变比 k，改变电压水平 | 主变有载/无载调压 |
| **无功补偿装置** | 并联电容器（发无功）/ 电抗器（吸无功） | 厂用母线上常见 |
| **调相机/SVC/STATCOM**（了解） | 动态无功调节 | 系统级的"电压稳定器" |

- **分层分区平衡原则**：无功要就近平衡，不能长途输送（长距离送无功=送电压降）；
- 中枢点电压管理：调度把电压目标定在中枢点（枢纽母线），各厂站按职责调。

**3. 发电机运行与电压**
- 发电机机端电压允许在额定 ±5% 内运行（AVR 维持）；
- 进相运行（欠励吸收无功）会降低机端电压并引起端部发热——有深度限制（电机学模块五已讲）。

**4. 易错点**：调压不是"拧电压旋钮"——本质是调无功平衡；乱调分接头可能引起无功倒送、电压失稳。

**与后续课程的连接**：电力系统自动化（AVC 自动电压控制）、调度运行（电压合格率考核）。

### 模块六 · 有功功率与频率调整 ★★★

**一句话定位**：频率是"有功劳"——全系统频率唯一，任何有功不平衡都表现为频率偏移。

**1. 核心机理**
- 频率由**全系统有功功率平衡**决定：发电 > 负荷 → 频率升高；发电 < 负荷 → 频率降低；
- 频率是全网统一量（同一时刻全系统频率相同），不能局部调。

**2. 三次调频 ★★★**
| 层次 | 谁在做 | 特点 |
|---|---|---|
| **一次调频** | 各机组调速器自动动作 | 有差调节：几秒内响应，但频率不能精确回到 50Hz |
| **二次调频（AGC）** | 调度中心自动发电控制 | 无差调节：分配出力，把频率拉回 50Hz |
| **三次调频（经济调度）** | 调度计划（日前/实时） | 按经济性优化机组出力分配 |

- 频率偏差公式（简化）：Δf = −ΔP / K（K 为系统单位调节功率）——负荷增加 ΔP，频率下降 Δf；
- **一次调频不够，二次调频兜底**：负荷突增后，一次调频把频率稳住（但偏低），AGC 再增出力把频率精确拉回 50Hz。

**3. 发电厂侧对应**
- 汽轮机调速器 = 一次调频执行机构（"有功看汽门"的上位概念）；
- AGC 信号下发到机组 → 汽门/水门动作 → 增发有功；
- 机组必须有足够调节余量，否则无法响应 AGC（"旋转备用容量"）。

**4. 易错点**：一次调频有差、二次调频无差；频率不能靠"局部调"解决，只能靠全网有功平衡。

**与后续课程的连接**：电力系统自动化（AGC、调速器、负荷频率控制）；调度（一次调频考核）。

### 模块七 · 短路计算基础 ★★★

**一句话定位**：电网最严重的故障是三相短路，短路电流有多大、怎么算——继保整定和设备校验全靠它。

**1. 短路的概念与目的**
- 短路类型：三相、两相、单相接地、两相接地；**三相短路电流最大、最严重**，是校验的基准；
- 短路计算两大目的：①**继电保护整定**（动作值、灵敏度校验）②**电气设备校验**（开关遮断容量、动热稳定）。

**2. 三相短路暂态过程 ★★**
- 短路电流 = **周期分量**（稳态，由电动势/电抗决定）+ **非周期分量**（按指数衰减——**电路原理模块四三要素法的直接应用**！）；
- 衰减时间常数由 X/R 决定：系统 X/R 大 → 衰减慢；
- **冲击电流**（最大瞬时值）：i_im = √2·K_im·I″（K_im 冲击系数，一般取 **1.8**，用于校验设备动稳定）。

**3. 短路电流实用计算 ★★★**
- 前提：忽略负荷、发电机用次暂态电抗 X″d、全网标幺值（模块二）；
- 步骤：①画等值电路（发电机、变压器、线路电抗）②全网归算到统一基准 ③化简到短路点得等值阻抗 X_Σ ④**I″ = E″ / X_Σ**（标幺值，E″≈1）；
- 例：X_Σ = 0.25（标幺），基准电流 I_B = S_B/(√3·U_B) = 100/(√3×115) ≈ 0.502kA（115kV 侧）→ 短路电流 I″ = (1/0.25)×0.502 ≈ **2.01kA**；
- 工程要点：离电源越近、系统越大，X_Σ 越小、短路电流越大。

**4. 易错点**：短路电流用次暂态电抗（不是同步电抗）；非周期分量使短路电流"先冲高再衰减"；冲击系数别记错。

**与后续课程的连接**：继保整定（定值=短路电流×系数）、发电厂电气（开关遮断容量、母线动热稳定校验）。

### 模块八 · 对称分量法与不对称故障（回顾深化）★★

**一句话定位**：继保第0课你已学过对称分量法，这里从"系统分析"角度把它讲完整——不对称故障计算就是"三张序网"的串联/并联。

**1. 对称分量法核心 ★★**
- 任何三相不对称量可分解为：**正序（a 相顺序）、负序（逆序）、零序（三相同相）**；
- 旋转算子 a = e^j120°：正序分量 = (A + a·B + a²·C)/3 等——继保课已默写过；
- **零序的特殊性**：三相同相 → 必须经**中性点/大地**才能流通 → 所以只有中性点接地系统才有零序电流（模块一的接地方式在这里闭环）。

**2. 序网与不对称故障（了解原理）**
- 三张序网：正序、负序、零序网络（各元件序阻抗：线路正负序相等、零序约为正序 3 倍；变压器零序阻抗与连接组别有关）；
- 单相接地：正负零序网**串联**；两相短路：正负序**并联**（无零序）；两相接地：三网并联；
- 结论记牢：**单相接地短路电流 < 三相短路电流（在直接接地系统）**，所以继保整定常以三相短路为基准。

**3. 与继保的闭环**：零序保护（第5课）、距离保护（第4课）的序分量逻辑，全部建立在对称分量法上。

**与后续课程的连接**：继保深化、发电机负序保护（转子发热）、系统不对称度考核。

## 六、自测题（学完全部模块后做）

1. 220kV 线路 20km，x = 0.4Ω/km，取基准 100MVA/220kV，线路电抗标幺值是多少？
2. 50MVA 变压器 u_k = 10.5%，基准 100MVA，电抗标幺值是多少？
3. 末端负荷 10MW、cosφ = 0.8，线路 R = 3Ω、X = 12Ω，末端电压 110kV，首端电压约为多少？
4. 系统负荷突增后，一次调频能把频率稳在 49.9Hz，为什么还不能算完？怎么才能回到 50Hz？
5. 写出三种调压手段，并说明"为什么说电压是系统无功平衡的表现"。
6. 为什么 110kV 及以上系统中性点要直接接地？这和零序保护有什么关系？
7. 三相短路时，短路电流由哪两个分量组成？冲击电流公式是什么？
8. 不对称故障计算中"三张序网"指什么？单相接地时三张网怎么连接？

### 答案

1. X = 0.4×20 = **8Ω**；Z_B = 220²/100 = **484Ω**；x* = 8/484 ≈ **0.0165**
2. x* = (u_k/100)×(S_B/S_N) = 0.105×100/50 = **0.21**
3. Q = P·tanφ = 10×0.75 = **7.5Mvar**；ΔU = (10×3 + 7.5×12)/110 = 120/110 ≈ **1.09kV**；首端电压 ≈ **111.1kV**
4. 一次调频是**有差调节**（调速器按转速偏差动作，频率稳定但不在 50Hz）；需**二次调频（AGC）**由调度中心分配出力，把频率**无差**拉回 50Hz
5. ①发电机励磁调压（AVR）②变压器分接头调压 ③无功补偿（电容器/电抗器）。无功经电抗传输产生压降 ΔU≈QX/U，全网无功充足电压就高、不足电压就低——所以电压水平由无功平衡决定
6. 110kV 及以上绝缘成本高，采用直接接地可限制过电压、降低绝缘投资；单相接地时形成大电流故障回路，产生**零序电流**——零序保护正是基于此（小电流接地系统无显著零序电流，靠选线装置）
7. **周期分量 + 非周期分量**（指数衰减）；i_im = **√2·K_im·I″**，K_im 冲击系数（一般取 1.8）
8. 正序、负序、零序三个序网络（由各元件序阻抗构成）；单相接地 = 三张序网**串联**（两相短路 = 正负序并联，两相接地 = 三网并联）
