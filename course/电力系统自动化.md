# 电力系统自动化 · 归纳总结

> 课程定位：六门主干课的**收口课**。前五门解决"设备怎么工作、系统怎么算、故障怎么跳"，这门解决"**谁来自动干这些活**"：发电机自动并列、励磁自动调节、频率/电压自动控制、变电站综合自动化、电网调度自动化——从厂里的发电机到调度大厅，一条自动化的链。学完它，六门课就串成了一张完整的图。
> 配套教材：李岩松《电力系统自动化（第2版）》，机械工业出版社
> 配套网课：华北电力大学《电力系统自动化》MOOC
> 学习顺序建议：本页默认你已完成前五门；每模块都会标出"复用哪门课的哪个工具"，学的时候回翻对照。

---

## 一、课程定位与学习方法

电力系统自动化的任务可以压成六个字：**安全、优质、经济**——安全（故障自愈、防崩溃）、优质（电压/频率合格）、经济（发电成本最低）。整门课一条主线：

```
发电侧自动装置           系统侧自动控制           电网侧自动化
自动并列 ─┐         频率调节（一次/二次/AGC）   调度自动化（SCADA/EMS）
励磁控制 ─┼──────→  电压控制（AVR/AVC/无功）──→ 变电站综合自动化
自动装置 ─┘         （低频减载/重合/备自投）     （测控/保护/远动）
```

学习方法：

1. **每块自动化都回答三问**：测什么（输入量）、控什么（输出量）、为什么（目的）——测控对象先理清，逻辑自然通；
2. **两对"自动调节"对比记忆**：频率↔有功（有功平衡定频率）、电压↔无功（无功平衡定电压）——系统分析模块五/六的调节思想，这门课把它"装置化"；
3. **时间尺度是考点**：一次调频秒级、二次调频分钟级、AGC 分钟~十几分钟级；励磁毫秒级、强励瞬时——谁快谁慢别混；
4. **收口视角**：把前五门课的知识点标在这门课对应模块旁，六门课就此闭环。

重要度标记：★★★ 必须掌握｜★★ 重点｜★ 了解

## 三、模块详解

### 模块一 · 自动化全景：安全·优质·经济与三层结构 ★★★

**一句话定位**：先看全局——自动化不是一台装置，是从"一台发电机"到"整个电网"的分层体系。

**1. 三大任务 ★★★**
- **安全**：自动装置快速切除故障、防系统崩溃（低频减载、解列、重合闸）；
- **优质**：频率 50±0.2Hz（大网）、电压在合格范围（自动调压调频）；
- **经济**：发电成本最低分配（AGC+经济调度）。

**2. 三层自动化结构 ★★★**
| 层次 | 范围 | 代表装置/系统 | 时间尺度 |
|---|---|---|---|
| 厂站层（就地） | 单台发电机/变电站 | 自动并列、AVR、备自投、低频减载 | 毫秒~秒 |
| 区域层 | 一个区域电网 | 调频厂 AGC、区域电压控制 | 秒~分钟 |
| 全网层 | 调度中心 | SCADA/EMS、状态估计、安全分析 | 分钟~小时 |

**3. 六门课收口总图（学完本页再回看这张表）★**
| 前置课 | 在本课的落点 |
|---|---|
| 电路原理 | 相量、暂态——并列相角差、励磁动态分析的工具 |
| 电机学 | 同步机功角特性、励磁——并列、AVR、PSS 的对象 |
| 电力系统分析 | 频率/电压调整、潮流——AGC、AVC、状态估计的物理 |
| 继电保护 | 重合闸、备自投、保护动作——自动装置与保护信息 |
| 发电厂电气部分 | 主接线、设备——变电站自动化控制的"一次对象" |

**易错点**：把"自动化"理解成"无人"不对——它是"人监控、机器执行"；三个时间尺度（毫秒/秒/分钟）是判断"哪层管什么"的钥匙。

**与现场的联系**：你单位 DCS/监控后台 + 调度电话 + 保护信息子站——三层结构就在你眼前。

### 模块二 · 发电机自动并列：准同期三条件、恒定越前时间 ★★★

**一句话定位**：新机组并网（或解列后再并）的"插头插入"动作——插早了会撞出巨大冲击电流。

**1. 并列方式 ★★**
- **准同期并列**（主流）：待并机与系统**电压差、频率差、相角差都合格时**合闸——冲击最小，正常并网都用它；
- **自同期并列**（备急）：先把未励磁的机组拖入同步再给励磁——冲击大，只在系统事故抢并时用。

**2. 准同期三条件 ★★★**
| 条件 | 允许范围（工程值） | 超标后果 |
|---|---|---|
| 电压差 ΔU | ≤ 额定电压的 5%~10% | 冲击无功电流 |
| 频率差 Δf | ≤ 0.2%~0.5% 额定（0.1~0.25Hz） | 相角差来回摆，合闸点难抓 |
| 相角差 δ | ≈ 0（合闸瞬间） | 冲击有功电流（最危险） |

**3. 恒定越前时间 ★★★**
- 断路器从合闸命令到主触头闭合有**固有动作时间 t_QD**（约 0.1~0.2s）——所以要在"相角差到 0"的 **t_QD 之前**发合闸命令；
- **恒定越前时间原理**：装置按"提前 t_QD 时刻的相角差=0 的预测点"合闸，让触头闭合时正好 δ≈0——这就是微机型自动准同期装置的核心算法；
- 配套的**频差检测**（测 Δf 大小和方向，先自动调速缩小频差）和**压差检测**（调励磁缩小电压差）。

**4. 电网之间并列 ★**
- 大系统之间并列要求更严（相角差、频差、功率冲击都校），由调度下令、用远方同期装置。

**易错点**：三条件里"相角差≈0"最重要（决定冲击电流的**有功分量**）；恒定越前时间是"提前一个开关动作时间"，不是"在 δ=0 的瞬间合闸"——说反了就完全错了。

**与现场的联系**：你单位每次机组并网，值长喊的"同期合闸"，就是这套逻辑在微机型装置里自动执行。

### 模块三 · 励磁自动控制：AVR、强励、灭磁、PSS ★★★

**一句话定位**：发电机的"油门+刹车"——自动调励磁维持机端电压（=自动调无功），故障时强励顶上去、跳闸时快速灭磁。

**1. 励磁系统构成 ★★**
- 励磁电源（励磁机/励磁变）→ 励磁调节器（AVR，核心）→ 转子绕组；
- **AVR 的任务**：维持发电机端电压恒定（其实质是自动调节无功输出——电机学"电压由无功定"的运行化）。

**2. 励磁调节特性 ★★**
- 调差系数：发电机电压随无功变化的斜率（正调差/负调差）；
- 并列运行机组间**无功按调差系数自动分配**——调差系数相同的机组分无功更均匀；
- 励磁电流↑ → 无功↑（过励）、励磁电流↓ → 无功↓甚至进相（欠励，发电厂电气部分模块八的进相运行就是 AVR 控制出来的）。

**3. 强励与灭磁 ★★★**
- **强励**：机端电压严重降低（如近区短路）时，AVR 把励磁电流**快速推到顶值**（额定励磁的 1.5~2 倍，持续数秒~几十秒）——维持电压、保住暂态稳定（电机学功角特性的工程应用：强励=关键时刻把 P_max 顶住）；
- **灭磁**：发电机跳闸后，励磁绕组储存的巨大磁场能量要**快速放掉**（否则转子绕组、绝缘烧毁）——灭磁开关+放电电阻/灭磁变，毫秒~秒级完成；
- **PSS（电力系统稳定器）**：抑制低频振荡——用转速/功率信号给励磁回路加阻尼（功角振荡的"减震器"，衔接系统分析静态稳定）。

**易错点**：强励是"故障时往上顶"、灭磁是"跳闸后往下泄"——方向相反的两个极端；PSS 抑制的是**低频振荡**（0.1~2Hz），不是高频谐波。

**与现场的联系**：主控室励磁屏上"AVR 自动/手动"切换、强励动作信号、灭磁开关位置——本模块全部实物。

### 模块四 · 频率与有功调节：一次/二次调频、AGC、经济分配 ★★★

**一句话定位**：电网频率=系统有功平衡的"体温计"——负荷突变时谁先动、谁跟上，就是本模块的层次。

**1. 一次调频（调速器）★★★**
- 负荷突增 → 频率下降 → **各机组调速器自动开大进汽/水门**，秒级响应；
- **有差调节**：调完后频率回不到 50Hz（偏差 Δf 与负荷变化量成正比，靠静态调差系数）；
- 公式：ΔP_G = −(1/R)×Δf（R 为调速器调差系数）——静态特性是条斜线。

**2. 二次调频（调频器/AGC）★★★**
- 一次调频的残差（频率偏差）由**调频厂/主调频机组**进一步调节，分钟级，**无差调节**——把频率拉回 50Hz；
- 手动：调度下令调频厂增减出力；自动：**AGC（自动发电控制）**闭环执行。

**3. AGC 与经济分配 ★★**
- AGC 的功能：跟踪负荷变化、维持频率、按**经济调度原则**分配各机组出力；
- **经济分配核心：等微增率原则**——各机组**边际成本（微增率）相等**时总成本最低（λ 相等法则）；
- 实际控制：区域控制误差 ACE → 分配到机组（响应+经济+约束三层目标）。

**4. 一次/二次对比表（高频考点）★**
| 项目 | 一次调频 | 二次调频/AGC |
|---|---|---|
| 执行者 | 各机组调速器 | 调频厂/调度 |
| 时间尺度 | 秒级 | 分钟级 |
| 调节性质 | 有差 | 无差 |
| 目的 | 快速止住频率下跌 | 频率拉回额定、经济分配 |

**易错点**：一次调频是"全厂一起本能反应"、二次调频是"指定的人负责纠正"——把执行者说混是常见错误；等微增率比的是**边际成本**不是平均成本。

**与现场的联系**：你单位 DCS 上的"调速器投入/AGC 投入"状态、调度下发的"出力曲线"——本模块的两个层次。

### 模块五 · 电压与无功控制：调压方式、AVC ★★

**一句话定位**：频率管有功，电压管无功——本模块把系统分析的无功电压调整"装置化"。

**1. 调压手段的优先级（现场套路）★★**
1. **发电机无功（励磁）调压**：最快、最方便（AVR 自动）——第一选择；
2. **变压器分接头调压**：改变变压器变比（有载调压 OLTC 可带电调）——无发电机处的常规手段；
3. **无功补偿设备**：电容器（发无功）、电抗器（吸无功）、调相机/STATCOM——网络层面调整；
4. 串联补偿、改变运行方式——辅助。

**2. 中枢点电压控制 ★★**
- 调度把全网电压管理抽象成"中枢点"（重要母线）——控制中枢点电压在合格带内，全网基本合格；
- 逆调压/顺调压/常调压：按负荷变化方向调中枢点电压（负荷重时抬高、轻时降低）。

**3. AVC（自动电压控制）★**
- 调度层的"电压 AGC"：SCADA 采集全网电压/无功 → 优化计算 → 下发到厂站（调励磁/切电容器/调分接）；
- 两级/三级 AVC 分层协调——和 AGC 是"频率/有功"的孪生兄弟（一个管频率、一个管电压）。

**易错点**：调压顺序"先无功后分接"（无功充足了才调变比）；电容器的无功出力**随电压平方变化**——电压低时电容器出力反而掉（"低电压时补偿效果打折"是考过的坑）。

**与现场的联系**：变电站里"自动投切电容器""有载调压动作记录"——AVC 的基层执行机构。

### 模块六 · 电力系统自动装置：重合闸、备自投、低频减载 ★★

**一句话定位**：故障后的"自愈三件套"——重合闸救瞬时故障、备自投保重要负荷、低频减载防频率崩溃。（与继保课重叠部分快速回顾，补充"系统自动"视角。）

**1. 自动重合闸（ARC）★★**
- 线路故障大多数是**瞬时性**（雷击闪络等）——保护跳闸后自动重合，成功率 60%~90%；
- 与继保配合：**"跳闸后延时重合、重合到永久故障再加速跳开"**（重合闸+后加速）；
- 两侧电源线路要检同期/检无压重合。

**2. 备用电源自动投入（备自投/BZT）★★**
- 工作电源失电 → 自动切备用电源（发电厂电气部分模块五已讲）——保证重要负荷不断电；
- 动作条件：工作电源无压无流、备用电源有压、延时躲短路切除。

**3. 低频减载（按频率自动减负荷）★★★**
- 事故时**有功缺额**→频率跌落——若不管，连锁跳机→**频率崩溃**；
- **分轮切除**：频率降到 49.5Hz 切第Ⅰ轮、49.0Hz 切第Ⅱ轮、48.5Hz 切第Ⅲ轮……（各轮切除一部分负荷，频率逐级稳住）；
- 特殊轮：低频 45~46Hz 以下切最后一轮（防止汽轮机低频损坏）；恢复轮在频率回升后分批恢复。
- 核心理念：**"丢车保帅"——用切除次要负荷，换整个电网不崩溃**。

**易错点**：低频减载是"按频率分轮切负荷"，不是按时间；重合闸对**永久性故障**会重合失败（所以有后加速），备自投要**躲开故障切除时间**。

**与现场的联系**：你单位线路重合闸压板、厂用电备自投、低压减载轮次表——三件套的实物与定值。

### 模块七 · 变电站综合自动化：功能分层、测控远动 ★★

**一句话定位**：把一座变电站的测量、保护、控制、通信装进一套系统——"保护屏+控制屏+表计屏"变成"监控后台+保护装置"。

**1. 综合自动化的功能 ★★**
- **测控**：四遥（遥测/遥信/遥控/遥调，见模块八）+ 本地监控；
- **保护**：继电保护装置就地独立（保护不依赖通信，永远最后防线）；
- **电压无功控制（VQC）**：自动调分接/切电容器（模块五的站内执行版）；
- **故障录波**：记录故障波形，事后分析（继保课的"黑匣子"）；
- **远动**：与调度通信（上传数据、接收集控指令）。

**2. 系统分层结构 ★★**
```
站控层（监控后台/操作员站/工程师站）
     ↑ 以太网
间隔层（保护装置/测控装置/故障录波，每间隔一套）
     ↑ 光纤/电缆
过程层（CT/PT 采样、开关状态——一次设备接口）
```
- 间隔层**就地保护**原则：即使站控层/通信全断，保护照样动作（自动化不能削弱保护可靠性）；
- 通信规约：IEC 61850（面向对象的变电站通信标准，光缆取代电缆、配置文件描述模型）——现代智能变电站的底座。

**3. 小电流接地选线等站内自动化 ★**
- 消弧线圈自动跟踪补偿、小电流接地选线（10/35kV 单相接地的自动处理——系统分析/发电厂电气部分提过的"绝缘监察三板斧"的自动化升级）。

**易错点**：综合自动化 ≠ 保护网络化——**保护装置是独立硬件、不依赖通信网**；"间隔层"是保护测控的家、"过程层"是采样开关的家，别层位混淆。

**与现场的联系**：你单位的监控后台、保护小室、保护信息子站——三层分层就在这。

---

### 模块八 · 电网调度自动化：SCADA、状态估计、EMS ★★

**一句话定位**：把整个电网搬进调度大厅——数据采集、状态感知、辅助决策，最后收口。

**1. SCADA（数据采集与监控）★★★**
- **四遥**：
  - 遥测（YC）：电压、电流、功率、频率等模拟量；
  - 遥信（YX）：开关位置、保护动作等状态量；
  - 遥控（YK）：远方合分闸；
  - 遥调（YT）：远方调整（AGC 出力、分接、无功）。
- 采集周期秒级，是调度自动化的一切基础。

**2. 状态估计（EMS 核心）★★**
- 问题：遥测有误差、可能有坏数据——直接用会算错；
- 作用：用**冗余测量 + 网络模型**估计全网真实状态（电压幅值/相角），**剔除坏数据**、补缺失测量；
- 地位：状态估计是潮流计算的"数据清洗+补全"——状态估计输出 → 潮流/安全分析才可信（衔接系统分析潮流模块）。

**3. EMS（能量管理系统）功能分层 ★★**
```
数据层：SCADA 采集 + 状态估计
分析层：潮流计算、安全分析（N-1）、短路计算（校核）
决策层：AGC/EDC 经济调度、电压控制、安全校正、预案
```
- 调度分层：国调→网调→省调→地调，逐级下发、数据逐级上报。

**4. 与前面各课的最终闭环 ★**
- 调度自动化采集的每一个数，都是前五门课的物理量：潮流（系统分析）、开关状态（继保/发电厂电气部分）、机组出力（电机学/发电厂电气部分）、保护动作信息（继保）——**自动化是"神经系统"，前五门是"肌肉和器官"**。

**易错点**：遥控≠遥调（开关合分 vs 连续量调整）；状态估计不是潮流计算（前者清洗数据、后者算结果）；AGC 和 AVC 一个管有功频率、一个管无功电压——别串。

**与现场的联系**：调度大厅的大屏幕、你单位上传调度的"四遥"表——全网自动化收口于此。

## 六、自测题（学完全部模块后做）

1. 准同期并列的三个条件及允许范围？恒定越前时间解决什么问题？
2. 一次调频和二次调频在"执行者、时间尺度、调节性质"三方面有什么区别？为什么一次调频是有差的？
3. 强励和灭磁分别针对什么情况？为什么强励能保暂态稳定？
4. 低频减载为什么分轮切除？各轮动作依据是什么？
5. SCADA 四遥是哪四遥？状态估计和潮流计算是什么关系？
6. 变电站综合自动化中，为什么保护装置必须"就地独立、不依赖通信"？

### 答案

1. 三条件：电压差 ≤5%~10% 额定、频率差 ≤0.2%~0.5% 额定、合闸瞬间相角差 ≈0。恒定越前时间解决"断路器固有动作时间"问题：合闸命令要在相角差到 0 之前提前 t_QD（开关固有时间）发出，让触头闭合时相角差正好为 0
2. 一次调频：各机组调速器/秒级/有差——调速器静态特性是条斜线（调差系数 R），负荷变化量与频率偏差成正比，所以调完回不到额定频率；二次调频：调频厂或 AGC/分钟级/无差——调频厂继续增减出力把频率拉回 50Hz，AGC 是自动执行者
3. 强励：机端电压严重降低（近区短路等）时把励磁快速推到顶值（1.5~2 倍额定），维持电压与暂态稳定——短路时抬高 E、保住功角不越过稳定极限；灭磁：发电机跳闸后快速泄放励磁绕组磁场能量，防止转子绕组过热/绝缘损坏
4. 事故有功缺额导致频率跌落，若一次/二次调频来不及或不足，频率会持续下跌→连锁跳机→频率崩溃。分轮切除：频率降到某阈值（如 49.5/49.0/48.5Hz…）切除对应轮次负荷，用丢次要负荷换全网不崩溃；特殊轮防汽轮机低频损坏、恢复轮在频率回升后分批恢复
5. 四遥=遥测（模拟量采集）、遥信（开关/保护状态）、遥控（远方合分）、遥调（远方调整连续量）。状态估计是潮流计算的"上游"：用冗余测量+网络模型估计真实状态、剔除坏数据；潮流计算在可信数据上算运行方式——先状态估计、后潮流/安全分析
6. 保护是电网安全最后防线：通信网/站控层故障时保护必须照常快速切除故障；若保护依赖通信，一次通信中断就可能扩大事故。综合自动化是"测量控制通信集成"，但保护**可靠性独立**原则不变
