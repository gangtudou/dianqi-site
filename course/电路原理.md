## 一、课程定位与学习方法

电路原理是电气专业的"地基课"：电机学、电力系统分析、继电保护、发电厂电气全部建立在它上面。对发电侧工作来说，**不需要学满全书，抓住"直流电阻电路 + 正弦稳态 + 三相 + 一阶暂态"这条主线就够用**，模块八的进阶工具了解即可。

**零基础自学建议**：

1. **先概念后公式**：每个小节先读懂"这是什么、为什么需要它"，再看公式；不要跳过解释直接背结论；
2. **配合生活类比理解**：电压=水压、电流=流量、电阻=阻力、电源=水泵，类比能帮你先建立直观认识；
3. **公式要会推导**：标 ★★★ 的公式最好能不看书写出推导过程，而不是只记结果；
4. **每题必算**：只看不算是学电路的常见死法，每模块至少做 5~10 道课后题；
5. **联系工作**：学到一个概念就问"这在变电站/发电厂里对应什么"，学完记忆最牢。

## 预备知识：动手学之前，先把这几样最基础的东西补齐

你在高中物理里见过"电压、电流、电阻、欧姆定律"这些词，但当时学得比较浅。电路原理这门课会反复使用它们，所以我们先用一节的时间，把它们和电路里的基础词汇一次性讲清楚。**这一节不涉及任何难题，看懂了再往后走。**

### 1. 电的本质：电荷在导线里流动

**电荷**是带电粒子携带的电量，就像水管里流动的"水"。物质由原子构成，原子里有带正电的质子、带负电的电子；通常物体正电和负电数量相等，对外不显电性。当导体（金属铜线）两端接上电源，导线里的自由电子就会被推着定向移动，**电荷的定向移动，就形成了电流**。

> **水流类比（贯穿整门课，随时回来对照）**：
> - 导线 = 水管；
> - 电荷 = 水管里的水；
> - 电流 = 水的流量（每秒流过多少水）；
> - 电压 = 水压（推动水流动的"压力差"）；
> - 电阻 = 水管的粗细和内壁摩擦（阻碍水流）；
> - 电源 = 水泵（不断提供压力差，让水循环流动）。

### 2. 电流 I：电荷流动的"快慢与多少"

**电流**定义为：单位时间内通过导线某一横截面的电荷量。

- 物理量符号：**I**（直流）或 **i**（随时间变化的瞬时值）；
- 单位：**安培**，符号 **A**。常用更小的单位：毫安 mA（1 mA = 10⁻³ A）、微安 μA（1 μA = 10⁻⁶ A）；
- 计算式：**I = q / t**（q 是 t 时间内通过截面的电荷量，单位库仑 C）。

**电流的方向**：物理学规定，**正电荷移动的方向为电流方向**。金属导线里实际移动的是带负电的电子，电子移动方向与电流方向相反——这个细节知道就行，电路计算里我们只关心规定的电流方向。

- **直流电（DC）**：方向和大小基本不变的电流，比如电池给手电筒供电；
- **交流电（AC）**：大小和方向随时间来回变化，家里插座、电网都是交流电，模块五专门讲。

### 3. 电压 U：推动电荷流动的"压力差"

#### 3.1 电位、电位差（电压）

**电位**（也叫电势）：电路中某一点相对于一个选定参考点（通常叫"地"，电位规定为 0）的带电程度高低，就像海拔以海平面为 0 来量高度。

**电压**（也叫电位差、电势差）：电路中**两点之间的电位之差**，记作 **U**。好比两点之间的水位差——有水位差水才会流，**有电位差电荷才会移动**。

- 单位：**伏特**，符号 **V**。常用千伏 kV（1 kV = 10³ V）、毫伏 mV（1 mV = 10⁻³ V）；
- 一点的电位记作 φ（读作"费"），A、B 两点之间的电压：**U_AB = φ_A − φ_B**；
- **电压降**：顺着电流方向经过一个元件，电位下降多少，就是这个元件上的电压降；**电压升**：从低电位走到高电位（比如经过电源），电位上升多少。

> 注意区分：**电位是"一点"相对参考点的高度；电压是"两点"之间的高度差**。说某点"电压是多少"是不严谨的，应该说"某点电位"或"某两点之间电压"。

#### 3.2 电源与电动势

**电源**（电池、发电机）是把其他形式能量（化学能、机械能）转换成电能的装置，它在自己的两个极之间维持一个稳定的电位差，好比水泵维持水压差。

**电动势**（符号 E 或 u_s）：电源内部把单位正电荷从负极"搬运"到正极所做的功，它描述电源本身能提供多大的"推动能力"。理想电源两端的电压就等于电动势。

### 4. 电阻 R：导体对电流的阻碍

**电阻**是导体对电流流动的阻碍作用，符号 **R**，单位**欧姆**，符号 **Ω**。更大的单位：千欧 kΩ（1 kΩ = 10³ Ω）、兆欧 MΩ（1 MΩ = 10⁶ Ω）。

**电阻的成因**：电流在金属导线里流动时，自由电子与导体内部的原子、杂质不断碰撞，形成阻碍。同样的电压下，电阻越大，电流越小——就像水管越细、内壁越粗糙，同样水压下流量越小。

#### 4.1 欧姆定律 ★★★（高中已有，这里说透）

在一段电路里，**导体中的电流跟这段导体两端的电压成正比，跟这段导体的电阻成反比**：

```
I = U / R        变形：U = I · R，R = U / I
```

- **U**：这段导体两端电压（V）；**I**：流过它的电流（A）；**R**：电阻（Ω）；
- 这条定律只对**线性电阻**（电阻值不随电压、电流改变的电阻，比如普通金属电阻）成立。

#### 4.2 开路与短路（两个极端情况）

- **开路（断路）**：电路断开，中间没有通路，电阻相当于**无穷大 R = ∞**，电流 I = 0；就像水管被剪断，水断了流；
- **短路**：电源两端被一根电阻几乎为 0 的导线直接连起来，R = 0，电流会变得极大，会烧坏电源、引发火灾，是电气事故中最危险的情况之一。

#### 4.3 电导 G：电阻的"反面说法"

既然 R 表示"阻碍"，反过来用 **G** 表示"传导电流的能力"，叫**电导**：

```
G = 1 / R
```

- 单位：**西门子**，符号 **S**；
- 电阻越大 → 电导越小；电阻越小 → 电导越大；
- 为什么要发明电导？**并联电路里用电导相加比用电阻倒数相加更方便**，模块二会用到。现在记住 G = 1/R 这个关系即可。

### 5. 功率 P 与能量：电流做功的快慢

水流推动水轮机转动要消耗能量；**电流通过灯泡、电机等负载时也会做功**，把电能变成光、热、机械能。

**电功率**：单位时间内电流做的功，符号 **P**，单位**瓦特**，符号 **W**（更大用千瓦 kW、兆瓦 MW）。

```
P = U · I
```

- 推导（了解即可）：电压 U 是"每库仑电荷经过元件释放的能量"，电流 I 是"每秒流过多少库仑"，两者相乘就是"每秒释放多少能量"= 功率；
- 电能（消耗的总能量）：**W = P · t**，单位**焦耳 J**；日常生活中说的"度电"：1 度 = 1 千瓦·小时（kWh）= 3.6×10⁶ J。

### 6. 电路的六个基础词汇（看图对照）

看一张最简单的电路：一节电池、一个开关、一只灯泡、几根导线连成闭合回路。里面会反复出现这些词：

| 词汇 | 是什么 | 类比 |
|---|---|---|
| **支路** | 电路中流过同一电流的一段通路（一根导线串着几个元件也算一条支路） | 一条独立的水管 |
| **节点** | 三条或三条以上支路的连接点（导线之间的分叉点） | 水管的三通/四通接头 |
| **回路** | 从某一点出发，经过若干支路，绕一圈回到原点所经过的闭合路径 | 一个闭合的水管环路 |
| **网孔** | 内部不包含其他支路的最简单回路（画在电路图上像一个个"网眼"） | 环路里最小的那个圈 |
| **负载** | 用电的元件（灯泡、电机、电阻等），消耗电能 | 水轮机 |
| **电源** | 提供电能的装置（电池、发电机） | 水泵 |

> 小提醒：**节点是"分叉点"，回路是"一圈闭合路径"，网孔是"里面没有别的支路的小回路"**——这三个概念模块一的两条定律会直接用到。

### 7. 一张完整电路的工作过程（把上面串起来）

1. 合上开关，电池两极之间的电压（电位差）加在灯泡两端；
2. 导线里的自由电子在电压推动下定向移动，形成电流；
3. 电流流过灯泡灯丝（有电阻），灯丝发热发光，电能变成热能和光能；
4. 只要电池电压维持、回路闭合，这个过程就持续下去；断开开关（开路），电流立刻消失。

**预备知识到这里结束。** 下面进入课程正式内容。如果你对"电压、电流、电阻、欧姆定律"已经很熟，可以快速浏览；但"节点、回路、网孔、开路、短路、电导"这几个词务必记住。

## 三、模块详解

### 模块一 · 电路模型与基本定律 ★★★

**一句话定位**：整个电路理论的两条"宪法"——基尔霍夫电流定律（KCL）和基尔霍夫电压定律（KVL）。后面所有分析方法、所有定理，本质上都是这两条定律的组合运用。

#### 1.1 什么是"电路模型"：为什么要把真实器件理想化

真实的灯泡、电机、电池内部情况很复杂，直接研究无从下手。电路理论的做法是：**把真实器件抽象成只保留某一种主要特性的"理想元件"，用导线把它们连成图，这张图就叫电路模型**。

比如：
- 只考虑"阻碍电流"这一特性的元件 → **理想电阻**；
- 只考虑"提供稳定电压"这一特性的元件 → **理想电压源**；
- 只考虑"储存电荷/磁场能量"的元件 → **电容、电感**（模块四讲）。

真实器件的多种特性，再由若干理想元件组合表示。**我们这门课分析的都是模型，不是实物照片。**

#### 1.2 三种最基本的理想元件

##### （1）电阻元件 R

- 特性：电压和电流满足欧姆定律 **u = R · i**；
- 它只消耗电能，把电能变成热，不储存能量；
- 符号与伏安特性：电压随电流成正比变化，画在 u-i 坐标上是一条过原点的直线。

##### （2）理想电压源

**是什么**：一个两端电压始终保持为给定值 u_s（直流）或给定时间函数的元件，不管外电路怎么接、流过它的电流多大，它两端电压都不变。

- 符号：圆圈内标 +、− 极性和 u_s；
- **关键理解**：电压源的电压是"自己定的"，**流过它的电流大小和方向由外电路决定**（电压源自己管不了电流）；
- 类比：一个压力恒定的水泵，不管下游水管怎么接，它出口压力始终不变；流量多少取决于管路。

##### （3）理想电流源

**是什么**：一个输出电流始终保持为给定值 i_s 的元件，不管外电路怎么接、它两端电压多大，输出电流都不变。

- 符号：圆圈内一个箭头（箭头方向就是电流方向）；
- **关键理解**：电流源的电流是"自己定的"，**它两端的电压由外电路决定**（电流源自己管不了电压）；
- 对比记忆：电压源"电压固定、电流听外电路"；电流源"电流固定、电压听外电路"。

> 这两种源合称**独立源**：它们的输出量不受电路中其他电压、电流控制。模块一最后会讲另一类"受控源"。

#### 1.3 参考方向：为什么要先人为假定电流、电压的方向 ★★

##### （1）为什么需要"参考方向"

在拿到一个未知电路时，我们**事先并不知道**电流到底往哪边流、电压哪端电位高。怎么办？**先在图上任意假定一个方向，叫参考方向（正方向）**，然后列方程计算：

- 算出来的结果 **为正**：实际方向与假定方向**相同**；
- 算出来的结果 **为负**：实际方向与假定方向**相反**。

如果不先假定方向，"电流是正是负"就没有比较标准，方程无法列写。**这是电路计算最重要的习惯：先标方向，再列方程，最后用正负号判断真实方向。**

##### （2）电流参考方向

在支路旁画一个箭头，标注 i，箭头方向就是电流参考方向。

##### （3）电压参考方向（极性）

在元件两端标 "+" 和 "−"，**电压 u 的参考方向规定为从 "+" 端指向 "−" 端**（即电位从 + 到 − 为电压降方向）。

##### （4）关联参考方向

对同一个元件，如果**电流参考方向从电压 "+" 端流入、从 "−" 端流出**，就称电压、电流为**关联参考方向**；反之叫非关联。

##### （5）用方向判断元件是"吸收"还是"发出"功率 ★★

- **关联参考方向**下，元件吸收的功率：**P = u · i**
  - P > 0：元件**吸收**功率（真的在耗能或储能，比如电阻、被充电的电池）；
  - P < 0：元件实际**发出**功率（它在向外供电，比如电池放电）。
- **非关联参考方向**下，吸收功率要写成 **P = −u · i**（判断标准不变：P > 0 吸收，P < 0 发出）。

> **易错提醒**：先看方向是否关联，再决定用 P = ui 还是 P = −ui；方向判断错了，功率正负就全反了。

#### 1.4 KCL（基尔霍夫电流定律）——节点上电流的"收支平衡" ★★★

##### （1）定律内容

**在任一时刻，对电路中的任意一个节点，流入该节点的电流之和等于流出该节点的电流之和。**

写成等式：

```
Σ i_流入 = Σ i_流出        或写成        Σ i = 0
```

（后者规定：流入节点的电流取正、流出取负，全部代数和为 0；也可以反过来规定，只要统一即可。）

##### （2）为什么成立

电流是电荷的流动，**电荷不会在节点上凭空堆积，也不会凭空消失**（电荷守恒）：流进来多少，就必须流出去多少。就像路口：开进路口的车 = 开出路口的车，路口不会无限堆车。

##### （3）推广：封闭面（广义节点）

KCL 不只适用于导线分叉点，也适用于**任意一个假想的闭合面**：把电路中一部分元件整个"包"起来，穿过这个封闭面的电流代数和同样为 0。比如一个三端元件、一个集成电路，都可以当成广义节点来用。

##### （4）怎么用 KCL

1. 标出各支路电流参考方向；
2. 选定节点，规定流入为正、流出为负；
3. 把接到该节点的所有支路电流写进 Σi = 0；
4. 一个节点列一个方程，n 个节点能列 n−1 个独立方程（最后一个节点的方程由其余方程推出）。

#### 1.5 KVL（基尔霍夫电压定律）——回路电压的"闭合为零" ★★★

##### （1）定律内容

**在任一时刻，沿电路中任意一个闭合回路绕行一周，回路中各段电压的代数和等于 0。**

```
Σ u = 0        也可以写成        Σ 电压降 = Σ 电压升
```

##### （2）为什么成立

电位是电路中每一点确定的高度。从回路某一点出发绕一圈回到**同一个点**，起点和终点是同一个点，电位当然相等——一路上的电位升降相互抵消，净变化为 0。类比爬山：从山脚出发绕一圈回到山脚，总高度变化必然是 0。

##### （3）怎么列 KVL 方程

1. 在回路中选定一个**绕行方向**（顺时针或逆时针，任选，统一即可）；
2. 沿绕行方向经过元件：
   - 遇到电压**降**（从 + 到 −），电压取正；
   - 遇到电压**升**（从 − 到 +），电压取负；
3. 全部相加等于 0；也可以直接写成"所有压降之和 = 所有电压升之和"。

##### （4）KCL 与 KVL 的关系

- KCL 管**节点**上电流的平衡，来自电荷守恒；
- KVL 管**回路**上电压的平衡，来自电位的单值性；
- 两条定律与元件是什么无关，**在集总参数电路（把每个元件的特性集中在一个点上、导线长度忽略不计的理想化电路模型，本课程研究的都是这一类）中都成立**，是后面一切分析方法的根基。

#### 1.6 受控源（了解）★

##### （1）独立源与受控源的区别

前面讲的电压源、电流源，输出量自己定，叫**独立源**。

**受控源**（也叫非独立源）：它的电压或电流**不由自己定，而是受电路中另一处的电压或电流控制**。好比一个"随从"，它的输出大小跟着别处某个量走。

##### （2）四种类型

按"控制量是电压还是电流"和"被控制量是电压还是电流"组合，共四种：电压控制电压源（VCVS）、电压控制电流源（VCCS）、电流控制电压源（CCVS）、电流控制电流源（CCCS）。

##### （3）分析时怎么处理

列方程时把受控源**先当成普通有源元件保留在电路里**，再把它的控制关系写成补充方程即可；模块三叠加定理中，**独立源可以逐个单独作用，受控源必须始终保留在电路里**（因为它不是"外加激励"，而是跟随电路状态变化的量）。

#### 1.7 与后续课程的连接

整个电力系统分析、继电保护的等值计算，本质上都是在大规模电路上反复运用 KCL、KVL：潮流方程是节点上的 KCL，回路电压校验是 KVL。把这两条定律练熟，后面课程的电路部分就有了根。

### 模块二 · 电阻电路的等效变换 ★★★

**一句话定位**：面对一堆电阻和电源，我们常常不需要知道内部每一个细节，只关心它对外两个接线端子表现出什么特性。**等效变换**就是把内部复杂的电路换成一个简单电路，让接在外面的部分感觉不到区别。继电保护短路计算、变电站等值电路化简，用的都是这个思想。

#### 2.1 先搞懂：什么叫"等效" ★★

##### （1）一端口（二端）网络

一个电路如果只引出**两个接线端子**（一个"入口"、一个"出口"），就叫**一端口网络**（也叫二端网络）。外面接什么东西，我们只通过这两个端子和它发生联系。

##### （2）等效的定义

如果电路 A 和电路 B，**在相同的两个端子上，电压 u、电流 i 的关系完全相同**（即接任何外部电路，端子上的电压、电流都一样），就说 A 和 B **对外等效**。

> **关键**：等效只要求"对外一样"，**内部可以完全不同**。就像换一个调速旋钮，只要拧到同样位置电机转得一样快，里面齿轮怎么排不影响外部感受。化简电路的目的，就是把麻烦的内部藏起来，只留对外表现一样的简单电路。

##### （3）什么是等效电阻

一个不含电源的一端口网络，端子上电压与电流之比 **R_eq = u / i**，就是它对外呈现的**等效电阻**。求等效电阻，是化简电阻电路最基本的任务。

#### 2.2 电阻的串联：首尾相接，电流相同 ★★★

##### （1）串联是什么

几个电阻**首尾依次相连**，中间没有分叉点，电流只有一条路可走，这种接法叫串联。

##### （2）串联的三个基本规律（用 KCL、KVL 推出来）

1. **电流处处相等**：因为是同一条支路，没有分叉，流过 R₁、R₂、R₃ 的是同一个电流 i（KCL：中间节点没有别的支路可分）；
2. **总电压等于各电阻电压之和**：沿串联路径绕过去，电位一段一段降落，总压降就是各段压降相加（KVL）：

```
U = U₁ + U₂ + U₃
```

3. 对每个电阻用欧姆定律 U_k = R_k · i，代入上式：

```
U = R₁·i + R₂·i + R₃·i = (R₁ + R₂ + R₃)·i
```

##### （3）串联等效电阻

把串联整体看成一个电阻 R_eq，它满足 U = R_eq · i，对比上式得到：

```
R_eq = R₁ + R₂ + R₃ + … + R_n
```

**串联越多，等效电阻越大**（像水管一段段接长、接细，阻力累加）。

##### （4）分压公式（串联最常用的结论）★★★

从 U_k = R_k · i 和 i = U / R_eq 联立，得到**每个电阻分到的电压**：

```
U_k = (R_k / R_eq) · U
```

**电阻越大，分到的电压越大**——电压按电阻大小成比例分配。这就是"串联分压"。

#### 2.3 电阻的并联：两端分别接在同一对节点上，电压相同 ★★★

##### （1）并联是什么

几个电阻**两端分别连到相同的两个节点**，电流在节点处分成几条支路走，这种接法叫并联。

##### （2）并联的三个基本规律

1. **各电阻两端电压相同**：它们接在同一对节点上，节点电位差只有一个，所以 U₁ = U₂ = U₃ = U；
2. **总电流等于各支路电流之和**（KCL：流进节点的总电流分成各支路电流）：

```
I = i₁ + i₂ + i₃
```

3. 各支路用欧姆定律 i_k = U / R_k 代入：

```
I = U/R₁ + U/R₂ + U/R₃ = U · (1/R₁ + 1/R₂ + 1/R₃)
```

##### （3）并联等效电阻

把整体看成等效电阻 R_eq，满足 I = U / R_eq，对比得：

```
1/R_eq = 1/R₁ + 1/R₂ + 1/R₃ + … + 1/R_n
```

**并联越多，等效电阻越小**（多条水管并排供水，总阻力下降）。

##### （4）用电导写并联（更简单）

预备知识里讲过 G = 1/R。上式两边直接变成：

```
G_eq = G₁ + G₂ + G₃ + …
```

**并联电导直接相加**，形式和"串联电阻直接相加"完全对称，算起来方便。

##### （5）两个电阻并联的口诀 ★★★

只有 R₁、R₂ 并联时，把倒数公式通分整理：

```
R_eq = R₁ · R₂ / (R₁ + R₂)
```

记成"**分子相乘、分母相加**"。

##### （6）分流公式（并联最常用的结论）★★★

并联各支路电压相同，i_k = G_k · U；总电流 I = G_eq · U，两式相除消去 U：

```
i_k = (G_k / G_eq) · I
```

**电导越大（电阻越小）的支路，分到的电流越大**——电流按电导大小成比例分配，这就是"并联分流"。

#### 2.4 星形（Y）与三角形（Δ）电阻电路的等效变换 ★★

##### （1）两种结构长什么样

- **星形 Y 形**：三个电阻一端共同连在一个中心节点上，另一端各自引出一个端子；形状像一个"三岔路口"；
- **三角形 Δ 形**：三个电阻首尾相连围成三角形，三个顶点各自引出一个端子；形状像"一个三角框"。

##### （2）为什么要变换

在一些复杂电路（比如后面三相电路、桥式电路）里，电阻之间既不是纯串联也不是纯并联，无法直接化简。如果这三个电阻正好接成 Y 或 Δ，**把 Y 换成对外等效的 Δ，或者反过来，就能让其余电阻恢复串并联关系**，继续化简。

##### （3）一般变换公式（遇到时套用即可）

**Δ → Y**：Y 形中接在端子 a 上的电阻：

```
R_a = R_ab · R_ca / (R_ab + R_bc + R_ca)
```

（与端子 a 相连的两条 Δ 边电阻相乘，除以 Δ 三边电阻之和；其余两个 Y 电阻同理轮换。）

**Y → Δ**：Δ 形中 a、b 两顶点之间的边电阻：

```
R_ab = (R_a·R_b + R_b·R_c + R_c·R_a) / R_c
```

（Y 三电阻两两乘积之和，除以 Δ 边对面那个 Y 电阻；其余两边同理轮换。）

##### （4）对称情况（三个电阻都相等，最常见）

若 Y 形三个电阻都是 R_Y，Δ 形三个电阻都是 R_Δ，等效关系简化为：

```
R_Δ = 3 · R_Y        （反过来 R_Y = R_Δ / 3）
```

#### 2.5 实际电源的两种模型及其互换 ★★

##### （1）真实电源不是理想的

理想电压源端电压永远不变，但真实电池用久了电压会掉，接上大负载时端电压明显下降——因为**真实电源内部有电阻**，叫**内阻**（r 或 R₀），电流流过内阻也要产生压降。

##### （2）实际电压源模型

**理想电压源 u_s 与一个内阻 R₀ 串联**，就构成实际电压源模型。带负载后，端子电压 = 电动势 − 内阻压降：

```
u = u_s − R₀ · i
```

##### （3）实际电流源模型

一个**理想电流源 i_s 与内阻 R₀ 并联**，构成实际电流源模型。内阻并联在端子上，分走一部分电流。

##### （4）两种模型可以等效互换

对外两个端子来说，两种模型表现相同，可以互相转换：

```
i_s = u_s / R₀        u_s = R₀ · i_s
```

内阻 R₀ 的大小不变，只是从"串联"搬到"并联"。

> **方向易错点**：互换时，**电流源箭头必须指向电压源的"+"端**（从低电位指向高电位，与电源内部电动势方向一致）。

#### 2.6 戴维南定理 ★★★（必会，工作中反复用）

##### （1）要解决的问题

电路中常常只需要研究**某一条支路**（比如接在两个端子上的负载 R_L），其余部分不管多复杂，都可以看成一个一端口网络。戴维南定理告诉我们：**这个含电源的一端口网络，对外可以等效成一个理想电压源串联一个电阻**，负载接上去算出来的结果和原电路完全一样。

##### （2）定理内容

任何一个**线性含源**一端口网络，对外电路来说，都可以等效为：

- 一个**开路电压 u_oc** 的理想电压源；
- 与一个**等效电阻 R_eq** 串联。

##### （3）两个量分别怎么求（三步法）★★★

**第一步：求开路电压 u_oc**
把待求负载断开，两个端子之间不接任何东西（开路状态），用 KCL、KVL 求出此时端子之间的电压，就是 u_oc。

**第二步：求等效电阻 R_eq**
把一端口网络内部的**独立源置零**：
- 理想电压源置零 → 用导线短路（电压变为 0）；
- 理想电流源置零 → 断开（电流变为 0）；
- 受控源**不能置零**，保留在电路里。

然后从两个端子看进去，求出剩下的无源电路的等效电阻，就是 R_eq。

**第三步：接上负载**
把负载 R_L 接回"u_oc 串联 R_eq"的等效电路，按简单串联电路计算负载电流、电压即可。

##### （4）含受控源时求 R_eq 的办法

如果网络内部含有受控源，不能直接把独立源置零后用串并联求电阻，改用**开路-短路法**：

```
R_eq = u_oc / i_sc
```

其中 i_sc 是把两个端子**短路**后流过短路线的短路电流。

#### 2.7 诺顿定理与最大功率传输 ★★

##### （1）诺顿定理（戴维南的"并联版本"）

同一个含源一端口网络，也可以等效为：**一个短路电流 i_sc 的理想电流源，与 R_eq 并联**。它和戴维南模型可以通过 2.5 的电源互换互相转换：

```
i_sc = u_oc / R_eq
```

##### （2）最大功率传输（负载能拿到多少功率）

负载 R_L 接在戴维南等效电路（u_oc 串 R_eq）上，负载电流 I = u_oc / (R_eq + R_L)，负载功率：

```
P_L = I² · R_L = u_oc² · R_L / (R_eq + R_L)²
```

数学上求极值可得：当 **R_L = R_eq** 时，负载获得最大功率：

```
P_max = u_oc² / (4 R_eq)
```

这叫**负载电阻等于电源内阻时获得最大功率**（阻抗匹配）。通信、信号电路里常用；电力系统供电一般不追求这个（内阻很小，追求高效率而非最大功率）。

继电保护计算"短路点等值阻抗"、变电站把电源侧化简成"一个电压源加内阻"，全是戴维南思想。看懂本模块，后续课程里各种"等值电路"你就知道是怎么来的了。

### 模块三 · 一般分析方法与电路定理 ★★

**一句话定位**：当电路无法通过串并联、星三角化简时，我们换一条路——**不化简，直接对整个电路列一组代数方程，解出每条支路的电压和电流**。电力系统潮流计算（几十万节点）用的就是节点电压法的大规模版本。

#### 3.1 为什么需要一套"列方程"的方法

模块二的等效变换只适合能化简的电路。遇到多电源、多支路、互相缠绕的电路，化简走不通。这时回到最根本的两条定律：**KCL 给节点列电流方程，KVL 给回路列电压方程**，再配合元件的伏安关系（欧姆定律等），未知数就能全部解出。本模块介绍三种列方程的方法，以及一条重要定理（叠加定理）。

先回顾预备知识里的三个词：**支路**（一条通路）、**节点**（分叉点）、**回路**（一圈闭合路径）、**网孔**（内部不含别的支路的小回路）。设电路有 b 条支路、n 个节点。

#### 3.2 支路电流法（最直观，方程最多）★

##### （1）思路

以**每条支路的电流**作为未知数，直接用 KCL、KVL 列方程求解。

##### （2）方程从哪里来、各列几个

- **KCL**：n 个节点中任选 **n − 1 个**列电流方程（最后一个节点的方程可由其余推出，不独立）；
- **KVL**：再选 **b − n + 1 个**独立回路列电压方程；
- 方程总数 = (n − 1) + (b − n + 1) = b，正好等于支路电流未知数个数，可解。

##### （3）评价

概念最直接，但支路一多方程数量巨大，手算几乎不用，只作为理解其他方法的基础。

#### 3.3 回路电流法（网孔法）★★

##### （1）思路

不再把每条支路电流当未知数，而是**假想每个独立回路里有一个"回路电流"在绕圈流动**；支路实际电流等于流过它的各回路电流的代数和。

##### （2）优点

未知数从 b 个减少到 **b − n + 1 个**（独立回路个数），方程更少。电路网孔形状清晰、网孔数不多时，手算很方便。

#### 3.4 节点电压法 ★★（工程手算与潮流计算的主流方法）

##### （1）思路

选一个节点作为**参考节点**（规定它电位为 0，也叫"地"），把其余每个节点相对于参考节点的**节点电压**作为未知数。先解出各节点电压，支路电压 = 两端节点电压之差，支路电流再由欧姆定律求出。

##### （2）方程怎么写（以一个节点 k 为例）

对节点 k 用 KCL：所有从节点 k 流出去的支路电流之和 = 流入节点 k 的电流源电流之和。把支路电流用"节点电压 ÷ 支路电导"表示后，方程整理成：

```
G_kk · U_k − Σ G_ki · U_i = I_sk
```

- **自导 G_kk**：接到节点 k 的所有支路电导之和，恒为**正**；
- **互导 G_ki**：节点 k 与相邻节点 i 之间公共支路的电导，方程中取**负**（因为相邻节点电压越高，从 k 流向 i 的电流方向越反过来）；
- 右边：电流源**注入**节点 k 取正，流出取负。

##### （3）遇到理想电压源怎么办

如果两个节点之间跨接一个理想电压源、且电压源两端都不接地，把这两个节点看成一个**超级节点**（超节点）：对超节点整体列 KCL，再补上"两节点电压之差等于电压源电压"的补充方程。

##### （4）方法取舍对照

| 方法 | 未知数（方程）个数 | 适合情况 |
|---|---|---|
| 支路电流法 | b（最多） | 仅作概念理解，很少手算 |
| 回路电流法（网孔法） | b − n + 1 | 网孔数量少、结构清晰 |
| 节点电压法 | n − 1（最少） | 节点数量少；工程手算与大规模潮流计算首选 |

#### 3.5 叠加定理 ★★

##### （1）什么是线性电路

**线性电路**：由线性元件（电阻满足 u = Ri 这种正比关系）和独立源组成的电路。线性的意思是：输入加倍，输出也加倍；多个输入共同作用的结果，等于每个输入单独作用结果相加。

##### （2）定理内容

**在线性电路中，多个独立源共同作用产生的任一响应（支路电压或支路电流），等于每个独立源单独作用时产生响应的代数和。**

- 某个独立源单独作用时，**其余独立源置零**：电压源短路、电流源开路；
- **受控源不是独立源，任何时候都保留在电路里**，不能置零；
- 最后把各分响应按参考方向代数相加。

##### （3）为什么功率不能叠加（高频易错点）

功率 P = u · i（电阻上是 i²R 或 u²/R），与电压、电流是**平方关系**，不是线性关系。必须先求出总电压、总电流，再算总功率；**不能把各分电源产生的功率直接相加**。

电力系统潮流计算就是大规模节点电压法：电网几万、几十万个节点，每个节点列一个节点电流平衡方程，计算机求解。本模块是理解潮流计算的思维入口。

### 模块四 · 动态电路暂态分析（三要素法）★★★

**一句话定位**：前面模块分析的都是电路稳定后的状态（直流稳态、交流稳态）。本模块研究**开关闭合/断开、电源接入或切除的一瞬间，电路从旧稳定状态过渡到新稳定状态的过程**——短路电流里的非周期分量衰减、变压器励磁涌流（模块七讲变压器时展开）衰减，都是这个模型。

#### 4.1 为什么直流电阻电路不够用了

模块一到三只含电阻，电阻上电压电流"同时"满足欧姆定律，电源一变，电流立刻跟着变。但电路里还有两类**储能元件**——电容和电感，它们能储存能量；能量不能瞬间凭空出现或消失，所以电压、电流不能突变，电路需要一段**过渡时间**才能重新稳定。这段过渡过程叫**暂态过程**（也叫动态过程）；稳定后的状态叫**稳态**。

#### 4.2 电容：储存电荷与电场能量的元件 ★★★

##### （1）结构是什么

**电容**由两块互相靠近、中间绝缘的金属极板组成，符号是两条平行短线。两块极板分别接到电源正、负极后，一块极板聚集正电荷，另一块聚集负电荷，极板之间形成电场，这就是**充电**；把充好电的电容从电源断开，电荷可以长期保留。

##### （2）电容上的电荷与电压关系

```
q = C · u_C
```

- q：极板电荷量（库仑 C）；u_C：极板间电压（V）；
- **C**：**电容**（电容量），单位**法拉 F**。常用微法 μF（1 μF = 10⁻⁶ F）、皮法 pF（1 pF = 10⁻¹² F）；
- C 越大，同样电压下能装的电荷越多。

##### （3）电流与电压的关系（微分形式）★★

电流是电荷随时间的变化率 i = dq/dt，代入 q = C·u_C：

```
i = C · du_C / dt
```

含义：**电容电流正比于电容电压的变化速度**。
- 电压不变（直流稳态）：du_C/dt = 0 → i = 0，**电容在直流稳态下相当于开路**；
- 电压变化越快，电流越大。

##### （4）电容电压为什么不能突变

电容储存电场能量 **W = ½ C u_C²**。能量不能瞬间跳变（否则功率无穷大，物理上不可能），所以 u_C 不能突变。这就是**换路定律**的电容形式：

```
u_C(0⁺) = u_C(0⁻)
```

#### 4.3 电感：储存磁场能量的元件 ★★★

##### （1）结构是什么

**电感**是用导线绕成的线圈（像弹簧一样一圈圈绕在骨架上），符号是一串弧形。电流流过线圈时，线圈内部建立磁场；电流变化时，变化的磁场会在线圈两端感应出电压（电磁感应，高中物理讲过）。

##### （2）电压与电流的关系（微分形式）★★

```
u_L = L · di_L / dt
```

- **L**：**电感量**，单位**亨利 H**。常用毫亨 mH（1 mH = 10⁻³ H）、微亨 μH；
- 含义：**电感电压正比于电感电流的变化速度**。
- 电流不变（直流稳态）：di_L/dt = 0 → u_L = 0，**电感在直流稳态下相当于短路**（一根无阻导线）。

##### （3）电感电流为什么不能突变

电感储存磁场能量 **W = ½ L i_L²**，能量不能瞬间跳变，所以 i_L 不能突变。换路定律的电感形式：

```
i_L(0⁺) = i_L(0⁻)
```

##### （4）一句话记忆两个元件

- **电容像"电压惯性"**：电压不能突变，直流稳态开路；
- **电感像"电流惯性"**：电流不能突变，直流稳态短路。

#### 4.4 换路瞬间：0⁻、0⁺ 与初始值求法 ★★★

##### （1）0⁻ 与 0⁺ 是什么意思

**换路**：电路中的开关动作、电源接入或切除，使电路结构发生改变。
- **t = 0⁻**：换路前一瞬间（旧稳态）；
- **t = 0⁺**：换路后一瞬间（暂态刚开始）。

##### （2）换路定律（初值的依据）

```
u_C(0⁺) = u_C(0⁻)        i_L(0⁺) = i_L(0⁻)
```

先求换路前旧稳态下的电容电压、电感电流，它们在换路瞬间保持不变。

##### （3）0⁺ 等效电路（求其他量初始值的工具）

在 t = 0⁺ 时刻：
- 已知电压的**电容**，用一个电压值等于 u_C(0⁺) 的**理想电压源**代替；
- 已知电流的**电感**，用一个电流值等于 i_L(0⁺) 的**理想电流源**代替；
- 其余电阻、电源保持原样。

在这个 0⁺ 等效电路上，就能求出各支路电压、电流的**初始值 f(0⁺)**。

#### 4.5 一阶电路三要素法 ★★★（本模块核心）

##### （1）什么是一阶电路

电路中只含**一个**储能元件（一个电容或一个电感），其余是电阻和电源，列出来的微分方程是一阶的，叫**一阶电路**。RC 电路、RL 电路都属于这一类。

##### （2）响应曲线长什么样

一阶电路在直流电源作用下，任何一个电压或电流，都是从**初始值 f(0⁺)** 按指数规律，逐渐过渡到**新的稳态值 f(∞)**，曲线形状只有"上升型"和"下降型"两种，由三个量决定，所以叫**三要素法**。

##### （3）三要素公式 ★★★

```
f(t) = f(∞) + [ f(0⁺) − f(∞) ] · e^(−t/τ)
```

三个要素分别是：

1. **初始值 f(0⁺)**：按 4.4 的换路定律 + 0⁺ 等效电路求出；
2. **稳态值 f(∞)**：t → ∞ 达到新直流稳态后的值。此时**电容开路、电感短路**，把电路按电阻电路化简后求出；
3. **时间常数 τ**：
   - RC 电路：**τ = R_eq · C**；
   - RL 电路：**τ = L / R_eq**；
   - R_eq 是从储能元件两端看进去、把独立源置零后的等效电阻。

##### （4）公式怎么理解

- t = 0 时：f(0) = f(∞) + [f(0⁺) − f(∞)] · e⁰ = f(0⁺)，正好是初始值；
- t → ∞ 时：e^(−t/τ) → 0，f(∞) = f(∞)，正好是稳态值；
- 中间时刻按指数曲线平滑过渡。

<ThreeElement />

#### 4.6 时间常数 τ 的物理意义 ★★

- **τ 越大，过渡过程越慢**（R 大、C 大或 L 大都使 τ 变大）；
- t = τ 时，过渡完成约 **63.2%**（剩余偏差降到初始偏差的 e⁻¹ ≈ 36.8%）；
- t = 3τ ~ 5τ 时，剩余偏差已不足 5%，工程上认为**过渡结束、电路进入新稳态**。

#### 4.7 三种响应与二阶电路（了解）★

##### （1）按激励分类

- **零输入响应**：换路后没有外加电源，仅靠储能元件初始储存的能量放电，响应从初值衰减到 0；
- **零状态响应**：储能元件初始能量为 0（零状态），由外加电源激励产生的响应，从 0 上升到稳态；
- **全响应** = 零输入响应 + 零状态响应，也可以拆成 **稳态分量 + 暂态分量**（暂态分量随时间衰减到 0，稳态分量长期存在）。

##### （2）二阶电路（了解概念即可）

同时含电容和电感、列出来是二阶微分方程的电路（如 RLC 串联），响应分三种情况：
- **过阻尼**：非振荡地缓慢回到稳态；
- **临界阻尼**：刚好不振荡、最快回到稳态；
- **欠阻尼**：围绕稳态值来回振荡、振幅逐渐衰减（衰减振荡）。

#### 4.8 与工作的连接

短路电流中的非周期分量按指数衰减、变压器励磁涌流几个周期内衰减、电容补偿装置投切涌流，都是一阶暂态模型；时间常数决定"衰减多快"，是继电保护整定中必须考虑的参数。

### 模块五 · 正弦稳态电路（相量法）★★★

**一句话定位**：电网发的、送的、用的全是**大小和方向随时间按正弦规律变化**的交流电。本模块先认识正弦量，再学会一件关键武器——**相量法**：把麻烦的正弦量运算变成复数代数运算。发电侧工作天天接触的电压、电流、有功、无功、功率因数，都在这一章。

#### 5.1 为什么电网使用交流电

直流和交流都能传输电能。交流电的最大好处：**用变压器可以方便地升高、降低电压**（模块七讲），高压输电损耗小，到用户端再降回安全电压；发电厂发电机结构也更适合发出交流电。所以全世界电网都是三相正弦交流电网。

#### 5.2 认识正弦量：周期、频率、角频率、幅值、初相 ★★★

##### （1）正弦波回顾（高中三角函数）

正弦电压随时间变化的一般表达式：

```
u(t) = U_m · sin(ωt + φ)
```

图像是一条上下振荡的光滑曲线（正弦波）。式中有三个独立要素，俗称**正弦量三要素**。

##### （2）周期、频率、角频率

- **周期 T**：正弦波完成一次完整振荡所用的时间，单位**秒 s**；
- **频率 f**：每秒振荡多少次，单位**赫兹 Hz**。f = 1 / T；我国市电频率 f = 50 Hz，周期 T = 0.02 s；
- **角频率 ω**：正弦函数里角度随时间变化的速度，单位**弧度/秒 rad/s**。关系：

```
ω = 2π f = 2π / T
```

50 Hz 市电的 ω = 2π × 50 ≈ 314 rad/s。

##### （3）幅值（最大值）U_m

正弦波振荡能达到的最大电压值（波形最高点的高度）。

##### （4）初相 φ 与相位差

- **相位**：ωt + φ 这个角度，决定正弦波此刻走到哪一点；
- **初相 φ**：t = 0 时的角度，决定波形在时间轴上的起点位置（波形左右平移）；
- **相位差**：两个同频率正弦量之间的角度之差，等于初相之差。电压比电流先达到峰值，叫"电压超前电流"；反之叫"滞后"。相位差的概念在分析电阻、电感、电容各自特性时非常关键。

#### 5.3 有效值：为什么市电标 220V 而不是 311V ★★

##### （1）定义

交流电的大小一直在变，用瞬时值不方便比较。**有效值**的定义：让交流电流和直流电流分别通过相同阻值的电阻，相同时间内产生相同热量，这个直流电流的数值就是交流电流的有效值。

##### （2）正弦量有效值与幅值的关系

数学推导（积分求平均热量）结果：

```
U = U_m / √2        I = I_m / √2
```

以市电为例：u(t) = 311 sin(314t) V，幅值 U_m = 311 V，有效值 U = 311/√2 ≈ 220 V。**日常说的 220V、电表上读数、设备铭牌额定电压，全是有效值。**

#### 5.4 先补一点复数基础（相量法的数学工具）★★★

不用怕，只需要下面这几条，看懂就能用。

##### （1）什么是复数

高中数学里，实数之外引入**虚数**单位 **j**（电路里不用 i，因为 i 已经留给电流了），规定：

```
j² = −1        j = √(−1)
```

一个复数写成 **a + jb**：a 叫**实部**，b 叫**虚部**（b 本身是实数）。

##### （2）复数的两种表示

- **代数形式（直角坐标）**：Z = a + jb，对应复平面上横坐标 a、纵坐标 b 的一个点；
- **极坐标形式（幅值+角度）**：Z = |Z| ∠θ，其中 |Z| 是复数到原点的距离（模），θ 是复数与正实轴的夹角（辐角）。

两种形式互换：

```
a = |Z| · cosθ        b = |Z| · sinθ
|Z| = √(a² + b²)      θ = arctan(b / a)
```

##### （3）复数运算规则

- **加减**：实部与实部相加减，虚部与虚部相加减：(a₁ + jb₁) ± (a₂ + jb₂) = (a₁ ± a₂) + j(b₁ ± b₂)；
- **乘除（极坐标最方便）**：模相乘除、辐角相加减：
  - Z₁∠θ₁ × Z₂∠θ₂ = Z₁Z₂ ∠(θ₁+θ₂)
  - Z₁∠θ₁ ÷ Z₂∠θ₂ = (Z₁/Z₂) ∠(θ₁−θ₂)；
- **j 的旋转意义**：一个复数乘以 j，等于在复平面上逆时针转 90°；乘以 −j 顺时针转 90°。

#### 5.5 相量：把正弦量换成复数来运算 ★★★

##### （1）为什么要换一种数学表示

直接对正弦函数做加减、求导、积分，会伴随大量三角函数变换，非常繁琐。注意到**同一个电路里所有电压、电流都是同一个频率 ω**（频率由电源决定，不会改变），真正需要关心的只有幅值（有效值）和初相两个量——它们正好可以组成一个复数。

##### （2）相量的定义

把正弦量**有效值**作为复数的模、**初相**作为复数的辐角，得到的复数就叫**相量**。电压相量、电流相量头顶加圆点区分：

```
u(t) = U_m · sin(ωt + φ)   →   Û = U ∠φ     （U = U_m/√2 是有效值）
i(t) = I_m · sin(ωt + ψ)   →   İ = I ∠ψ
```

**相量不是瞬时值，也不是正弦量本身**，它只是携带了"有效值+初相"信息的复数；频率 ω 大家都一样，不再写进相量。运算结束后，再把相量还原成正弦表达式即可。

##### （3）相量法的价值

- 同频率正弦量的加减 → 对应相量复数的加减；
- 电感、电容的微分、积分关系 → 变成乘以 jω 或除以 jω 的代数运算；
- 整个直流电路的分析方法（串并联、节点法、叠加、戴维南）**可以原封不动搬到相量形式的交流电路里**。

#### 5.6 三种元件在正弦交流下的特性与阻抗 ★★★

##### （1）电阻 R

电压、电流**同相位**（同时到达峰值、同时过零），关系和直流一样：

```
Û = R · İ
```

##### （2）电感 L

电感电流变化时感应电压阻碍变化，结果是**电压超前电流 90°**。定义**感抗**（电感对交流的阻碍作用）：

```
X_L = ω L
Û = j X_L · İ = jωL · İ
```

- 频率越高、电感越大，感抗越大；直流（ω = 0）时 X_L = 0，电感相当于短路（呼应模块四）。

##### （3）电容 C

电容电压滞后电流 90°（电流超前电压 90°）。定义**容抗**：

```
X_C = 1 / (ω C)
Û = İ / (jωC) = −j X_C · İ
```

- 频率越高、电容越大，容抗越小；直流（ω = 0）时 X_C → ∞，电容相当于开路（呼应模块四）。

##### （4）阻抗 Z 与导纳 Y

把电阻、电感、电容串联起来，整体对交流的阻碍用**阻抗**描述：

```
Z = R + jX          X = X_L − X_C（电抗）
|Z| = √(R² + X²)    阻抗角 φ = arctan(X / R)
Û = Z · İ
```

- R 是电阻部分（耗能），X 是**电抗**（由电感、电容贡献，不耗能）；
- 阻抗模 |Z| 是电压有效值与电流有效值之比；阻抗角就是电压超前电流的相位差；
- 阻抗的倒数叫**导纳** Y = 1/Z = G + jB（G 电导、B 电纳），并联分析时使用。

> 这就是后续继电保护课里"为什么用 Z（阻抗）而不只说 R（电阻）"的由来：交流电路的阻碍是电阻与电抗合成的。

#### 5.7 相量形式的 KCL、KVL 与电路分析方法

正弦稳态下，KCL、KVL 对相量照常成立：

```
Σ İ = 0（节点）        Σ Û = 0（回路）
```

模块二、模块三的串并联化简、节点电压法、叠加定理、戴维南定理，把电阻 R 换成阻抗 Z、电压电流换成相量，**全部可以直接套用**。

#### 5.8 交流电路的功率与功率三角形 ★★★（工作最常用）

##### （1）三种功率

设电压、电流有效值为 U、I，电压超前电流的阻抗角为 φ：

| 功率 | 符号与公式 | 单位 | 物理含义 |
|---|---|---|---|
| **有功功率 P** | P = U I cosφ | 瓦 W | 真正做功、被消耗掉变成热/机械能的部分 |
| **无功功率 Q** | Q = U I sinφ | 乏 var | 与电感磁场、电容电场来回交换、不被消耗的部分 |
| **视在功率 S** | S = U I | 伏安 VA | 设备额定容量，电压电流有效值的乘积 |

##### （2）功率三角形与功率因数 ★★★

三者构成直角三角形：S 是斜边，P 是邻边，Q 是对边：

```
S² = P² + Q²
功率因数  cosφ = P / S = R / |Z|
```

- **功率因数 cosφ** 衡量电能被"有效利用"的程度：越接近 1 越好；
- **无功的通俗理解**：电动机、变压器要建立磁场必须和电源来回交换能量，这部分能量不被消耗，但占用了线路和设备容量，就是无功。就像喝酒时泡沫占了杯子体积——酒是有功，泡沫是无功；
- **提高功率因数**：工矿企业大量感性负载（电动机）使 cosφ 偏低，通常**并联电容器**向电网"就地提供"无功，减少线路传输的无功电流，降低损耗。

##### （3）现场单位口诀

**MW 是真正用掉的有功，Mvar 是维持磁场/电压需要的无功，MVA 是设备铭牌扛得住的视在容量**——看变电站铭牌、呼表时对照理解。

#### 5.9 谐振（了解概念）★

##### （1）串联谐振

R、L、C 串联，当感抗与容抗大小相等（X_L = X_C）时，电抗 X = 0，整个电路阻抗最小、等于 R，电流最大，叫**串联谐振**（电压谐振）。谐振角频率：

```
ω₀ = 1 / √(LC)        f₀ = 1 / (2π√(LC))
```

谐振时电感、电容上的电压可能达到电源电压的 Q 倍（**品质因数** Q = ω₀L/R = 1/(ω₀CR)）。

##### （2）并联谐振

L、C 并联谐振时阻抗最大、总电流最小（电流谐振），常用于选频、滤波电路。

### 模块六 · 三相电路 ★★★

**一句话定位**：实际电网的发电、输电、配电、用电都在**三相**框架下完成。这一章是发电侧最对口的内容：发电机绕组接法、变压器接线、母线电压、三相短路，都离不开本章概念。

#### 6.1 为什么电网是"三相"的

一台交流发电机里，转子旋转时，定子上装有**三个空间位置相差 120° 的绕组**，各自感应出一个频率相同、幅值相同、初相互差 120° 的正弦电压，这就是**对称三相电源**。

相比单相，三相发电、输电更经济（同样材料输送更多功率），三相电动机结构简单、运行平稳。所以全世界采用三相制。

#### 6.2 两个基本概念：相电压/线电压、相电流/线电流 ★★★

##### （1）星形（Y）接法

把三个绕组（或三个负载）的一端连在一起，形成公共节点叫**中性点（中点，N）**，另一端各引出一根线（端线，俗称火线）。

- **相电压**：每相绕组（负载）两端、即端线与中性点之间的电压，记 U_p；
- **线电压**：两根端线之间的电压，记 U_l；
- **相电流**：流过每相绕组（负载）的电流；**线电流**：端线上流过的电流。

##### （2）三角形（Δ）接法

三个绕组（负载）首尾相连成闭合三角形，三个连接点各引出一根端线，没有中性点。

##### （3）对称电路中的 √3 关系（必背）★★★

用相量画出三个对称电压（互差 120°），线电压等于两个相电压之差，由相量三角形几何关系得到：

| 接法 | 线电压与相电压 | 线电流与相电流 |
|---|---|---|
| 星形 Y | U_l = √3 · U_p（线电压超前对应相电压 30°） | I_l = I_p |
| 三角形 Δ | U_l = U_p | I_l = √3 · I_p（线电流滞后对应相电流 30°） |

记忆口诀：**星形 Y 升电压（√3），三角形 Δ 升电流（√3）**。

常见数值：配电变压器副边星形接法，相电压 220V，线电压 √3 × 220 ≈ 380V——这就是家用"220V、380V"两个电压的来历。

#### 6.3 对称三相电路的计算：化为一相 ★★★

##### （1）什么叫对称

**对称三相电源**：三相电压幅值相等、频率相同、相位互差 120°；**对称三相负载**：三相阻抗完全相同。电源对称、负载对称，整个电路叫对称三相电路。

##### （2）化为一相计算

对称情况下三相状态完全相同、只是相位依次差 120°。Y-Y 连接时，发电机中性点与负载中性点电位相等，可以直接短接。**只取出其中一相（比如 A 相）按单相电路计算**，得到该相的电压、电流；B、C 两相按相位差 ±120° 直接写出即可，不必重复列方程。

#### 6.4 三相功率 ★★★

对称三相电路中，三相总功率（用线电压、线电流表示）：

```
P = √3 · U_l · I_l · cosφ
Q = √3 · U_l · I_l · sinφ
S = √3 · U_l · I_l
```

注意：公式里的 **cosφ 是每相负载的阻抗角**（相电压与相电流的相位差），不是线电压与线电流之间的夹角。测量三相功率有三表法（三相四线制）和两表法（三相三线制），原理了解即可。

#### 6.5 中线的作用（现场铁规矩）★★★

##### （1）三相四线制

星形接法的中性点引出一根**中线（零线 N）**，三根端线加一根中线就是三相四线制（常见于低压配电 380/220V）。

##### （2）中线保证不对称负载电压平衡

如果三相负载大小不一样（不对称），没有中线时各相电压会互相牵扯；**中线的存在强制把负载中性点电位拉住，使各相负载两端电压仍然等于电源相电压，互不影响**。

##### （3）中线不许装保险、不许断

**中线上不允许安装熔断器（保险）和开关**。中线一旦断开，负载中性点电位会漂移（**中性点位移**），导致有的相电压升高、有的相电压降低，可能烧毁单相用电设备——这是电气安装与运行的现场铁规矩。

#### 6.6 不对称三相与中性点位移（了解）★

负载不对称又无中线时，中性点电位偏离电源中性点，各相电压不再对称：负载阻抗大的一相电压偏高，阻抗小的一相电压偏低。调度运行中说的"三相不平衡"，就是指三相电流、电压幅值或相位不对称的状态。

#### 6.7 与后续课程的连接

发电机与变压器的 Y/Δ 接线、并网时的电压匹配、三相短路电流计算、厂用母线电压，全部在三相框架内展开。

### 模块七 · 耦合电感与变压器 ★★

**一句话定位**：这一章是从"电路"通向"电机学"的桥。电力变压器、电流互感器 CT、电压互感器 PT，本质都是两个线圈之间靠磁场传递能量的耦合电感装置。

#### 7.1 互感现象：两个线圈之间的磁场联系 ★★

##### （1）电磁感应回顾（高中物理）

线圈流过变化的电流，线圈周围产生变化的磁场；变化的磁场穿过另一个线圈，会在另一个线圈两端感应出电压，这就是**电磁感应现象**。

##### （2）互感与自感

- 线圈 1 自己的电流变化，在自身感应出电压，叫**自感**（就是模块四的电感 L₁）；
- 线圈 1 的电流变化，穿过线圈 2，在线圈 2 感应出电压，这种两个线圈之间的磁场联系叫**互感**，对应的互感量记 **M**；
- 两个线圈距离越近、绕得越紧、共用铁芯，互感越强。

##### （3）耦合线圈的电压关系

线圈两端电压由自感电压和互感电压两部分叠加：

```
u₁ = L₁ · di₁/dt ± M · di₂/dt
u₂ = L₂ · di₂/dt ± M · di₁/dt
```

互感项前面取正还是取负，取决于两个线圈电流与绕向的配合，这就要用到**同名端**。

#### 7.2 同名端与耦合系数 ★★

##### （1）同名端是什么

两个线圈绕向相同的对应端子叫**同名端**（电路图上用"·"标记）。**当电流同时从两个线圈的同名端流入时，两个线圈产生的磁场方向相同、互相加强（助磁）**；从异名端流入则磁场互相削弱（去磁）。

##### （2）作用

列互感电压方程时，电流都从同名端流入，互感电压取正；否则取负。同名端决定互感项的正负号。

##### （3）耦合系数 k

```
k = M / √(L₁ · L₂)        0 ≤ k ≤ 1
```

k 越接近 1，说明两个线圈磁场耦合越紧密；k = 1 叫**全耦合**（无漏磁）。铁芯变压器 k 接近 1，空心线圈 k 较小。

#### 7.3 理想变压器 ★★★（发电侧最常用）

##### （1）什么是理想变压器

把实际变压器理想化得到的模型：线圈电感无穷大、无损耗、无漏磁、耦合系数 k = 1。它有两个端口：**原边（初级、一次侧）**接电源，**副边（次级、二次侧）**接负载，靠磁场联系，没有电的直接连接。

##### （2）变比

原边匝数 N₁、副边匝数 N₂，定义**变比**：

```
n = N₁ / N₂
```

##### （3）电压关系

理想变压器两侧绕组每匝感应电压相同，所以电压比等于匝数比：

```
u₁ / u₂ = N₁ / N₂ = n
```

升压变压器 n < 1（副边匝数多），降压变压器 n > 1。

##### （4）电流关系

理想变压器本身不消耗功率，原边输入功率等于副边输出功率（u₁i₁ = u₂i₂），结合电压比得：

```
i₁ / i₂ = N₂ / N₁ = 1 / n
```

注意参考方向约定：副边电流方向与原边在变压器内部的流向相反。

##### （5）阻抗折算（后续课程反复用）★★★

副边接负载 Z_L，从原边两端看进去等效到原边的阻抗为：

```
Z' = n² · Z_L
```

**变压器把副边阻抗放大了 n² 倍**。继电保护、电机学分析中"把阻抗从低压侧折算到高压侧"，依据就是这条关系。

#### 7.4 实际变压器的组成（了解）★

实际变压器 ≈ 理想变压器 + 原副边漏阻抗（漏磁对应的小电感和线圈电阻）+ 励磁支路（建立主磁场、带空载损耗）+ 铁损铜损。完整等值电路在《电机学》课程展开。

#### 7.5 与后续课程的连接

### 模块八 · 进阶工具（了解级）★

这些内容发电侧日常工作基本用不上，学有余力再看。这里只做**概念扫盲**：知道"这是什么、用来解决什么问题"，遇到时能回来查阅即可，推导不要求掌握。

#### 8.1 非正弦周期电流电路与谐波 ★

- **问题背景**：电网电压本应是完美正弦波，但整流设备、非线性负载会让电流、电压波形发生畸变，不再是正弦波；
- **数学工具**：**傅里叶分解**——任何周期性非正弦波形都可以拆成一个直流分量（基值）加一系列不同频率的正弦分量，频率最低的叫**基波**，其余整数倍频率的叫**谐波**（2 次、3 次……）；
- 非正弦量有效值：U = √(U₀² + U₁² + U₂² + …)，平均功率等于各次谐波单独产生的功率之和；
- 应用：谐波分析、谐波抑制与滤波，是电能质量治理的数学基础。

#### 8.2 拉普拉斯变换法（s 域分析）★

- **问题背景**：模块四的一阶、二阶电路用微分方程描述；高阶、复杂电路微分方程列解困难；
- **思路**：像相量把正弦量变成复数那样，**拉普拉斯变换把微分方程变成 s 域（复频域）的代数方程**，解代数方程后再反变换回时间函数；
- 这是动态电路的通用解法，思路了解即可，具体变换公式在后续专业课程用到时再查。

#### 8.3 二端口网络 ★

- **问题背景**：很多电路模块只有两个输入端子、两个输出端子（滤波器、放大器、变压器），内部不需要逐个元件分析；
- **思路**：把它当成"黑箱"，用一组参数（Z 参数、Y 参数等）描述两个端口电压、电流之间的关系，外部电路直接用这组参数计算；
- 应用：滤波器设计、多级网络级联分析。

#### 8.4 网络函数与频率响应 ★

- **网络函数**：线性电路中，输出响应相量与输入激励相量之比，是频率的函数；
- **频率响应**：包括**幅频特性**（幅值随频率变化）和**相频特性**（相位随频率变化）；
- 应用：不同频率信号经过电路后被放大或衰减的规律，是滤波器、选频电路设计的核心概念。

## 十一、自测题（学完全部模块后做，先回顾对应小节再动笔）

1. 6Ω 与 3Ω 两电阻并联，等效电阻是多少？（考点：两电阻并联口诀 R_eq = R₁R₂/(R₁+R₂)）
2. 电压源 12V（内阻 2Ω）外接 4Ω 负载，求负载电流和负载功率。（考点：实际电源模型，串联总电阻用欧姆定律）
3. 电容 2μF 充电至 10V，储存能量是多少？（考点：电容储能 W = ½Cu²）
4. R = 10kΩ、C = 100μF 的一阶 RC 电路，时间常数 τ 是多少？约几倍 τ 后视为稳定？（考点：τ = RC）
5. 正弦电压 u = 311sin(314t + 30°) V，求有效值、频率、初相。（考点：有效值 U = U_m/√2，ω = 2πf）
6. R = 3Ω、X = 4Ω 串联，端电压 100V，求阻抗模、电流、有功、无功、功率因数。（考点：阻抗 Z = R+jX，功率三角形）
7. 对称三相负载星形连接，相电压 220V、每相电阻 10Ω（纯阻），求线电压、线电流、三相总有功功率。（考点：Y 形 U_l = √3 U_p、I_l = I_p、P = √3 U_l I_l cosφ）
8. 理想变压器变比 n = 10，副边接 4Ω 负载，从原边看等效阻抗是多少？（考点：阻抗折算 Z' = n² Z_L）

### 答案与简要过程

1. R_eq = 6×3/(6+3) = **2Ω**。
2. 串联总电阻 = 2+4 = 6Ω，I = 12/6 = **2A**；负载功率 P = I²×4 = 2²×4 = **16W**。
3. W = ½ × 2×10⁻⁶ × 10² = **100 μJ**。
4. τ = RC = 10×10³ × 100×10⁻⁶ = **1s**；约 3~5 倍 τ（3~5s）视为稳定。
5. U = 311/√2 ≈ **220V**；f = ω/(2π) = 314/(2π) = **50Hz**；初相 **30°**。
6. |Z| = √(3²+4²) = **5Ω**；I = 100/5 = **20A**；cosφ = 3/5 = **0.6**；P = U·I·cosφ = 100×20×0.6 = **1200W**；Q = 100×20×0.8 = **1600 var**。
7. U_l = √3×220 ≈ **380V**；Y 形 I_p = I_l = 220/10 = **22A**；P = √3×380×22×1 ≈ **14480W ≈ 14.5kW**。
8. Z' = n² × 4 = 10²×4 = **400Ω**。
