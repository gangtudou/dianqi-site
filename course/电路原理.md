## 一、课程定位与学习方法

电路原理是电气专业的"地基课"：电机学、电力系统分析、继电保护、发电厂电气全部建立在它上面。对发电侧工作来说，**不需要学满全书，抓住"直流电阻电路 + 正弦稳态 + 三相 + 一阶暂态"这条主线就够用**，本书第13章以后的内容了解即可。

学习方法（推荐给在职/自学）：

1. **先整体后细节**：先看本页知识地图，知道这门课解决什么问题，再逐模块学；
2. **公式要能默写**：下面标 ★★★ 的公式必须能不看书写出来；
3. **每题必算**：只看不算是学电路的常见死法，每模块至少做 5~10 道课后题；
4. **联系工作**：学到一个概念就问"这在变电站/发电厂里对应什么"，学完记忆最牢。

重要度标记：★★★ 必须掌握（考试与工作都用得上）｜★★ 重点（会算会用）｜★ 了解（知道概念即可）

## 三、模块详解

### 模块一 · 电路模型与基本定律 ★★★

**一句话定位**：整个电路理论的两条"宪法"——基尔霍夫定律，其余一切方法都由它们推导。

**1. 参考方向（最重要的习惯）**
- 电流、电压方向都是**人为假定的**（画箭头），计算结果为正说明与假定一致，为负则相反；
- **关联参考方向**：电流从电压"+"端流入元件。此时功率 P = UI，P > 0 表示元件吸收功率（耗能/储能），P < 0 表示发出功率；
- 非关联方向时 P = −UI。**易错点：先判断方向再套功率公式。**

**2. 三种基本元件**
- 电阻：u = Ri，欧姆定律；开路 R = ∞，短路 R = 0；
- 理想电压源：端电压恒为 u_s，电流由外电路决定（可正可负）；
- 理想电流源：电流恒为 i_s，端电压由外电路决定。

**3. KCL（电流定律）——节点上电流的"收支平衡"**
- 任意节点（或封闭面）：流入电流之和 = 流出电流之和，即 Σi = 0；
- 记忆：电流不会凭空产生或消失。

<KclDemo />

**4. KVL（电压定律）——回路电压的"闭合为零"**
- 任意回路，沿绕行方向电压代数和 = 0（电压降 = 电压升）；
- 记忆：绕一圈回到原点，电位必须还原。

<KvlDemo />

**5. 受控源（了解）**：四种（电压/电流控制），分析时当成"有源元件"保留即可，后面的方法都适用。

**与后续课程的连接**：整个电力系统分析、继电保护的等值计算，本质都是在大规模 KCL/KVL 上展开。

### 模块二 · 电阻电路的等效变换 ★★★

**一句话定位**：把复杂电路"化简成一张嘴"，只关心端口对外表现——戴维南定理是继保短路计算的核心工具。

**1. 串并联与分压分流**
- 串联：R_eq = R1 + R2 + ...；分压 u_i = (R_i / R_eq) · U；
- 并联：1/R_eq = 1/R1 + 1/R2 + ...（或用电导 G）；分流 i_i = (G_i / G_eq) · I；
- 两个电阻并联口诀：R_eq = R1·R2 / (R1 + R2)。

<VoltageDivider />

**2. 星形-三角形变换（记住方向即可）**
- Δ → Y：Y 中某电阻 = 与之相连两 Δ 边电阻的乘积 ÷ Δ 三边之和；
- Y → Δ：Δ 中某边电阻 = Y 三电阻两两乘积之和 ÷ 对边那个 Y 电阻。
- 用到场景少，遇到"三个电阻围成三角形"时回来查即可。

**3. 实际电源互换**
- 实际电压源（u_s 串 R）↔ 实际电流源（i_s 并 R）：i_s = u_s / R，u_s = R · i_s；**注意电流源方向指向电压源"+"端。**

**4. 戴维南定理 ★★★（必会）**
- 含源线性一端口网络 → 等效为：**开路电压 u_oc 串联等效电阻 R_eq**；
- 求法三步：① 断开负载，求端口开路电压 u_oc；② 独立源置零（电压源短路、电流源开路），求端口看入电阻 R_eq；③ 负载接到 u_oc 与 R_eq 串联的支路上；
- 含受控源时：R_eq = u_oc / i_sc（开路电压 ÷ 短路电流）。

<Thevenin />

**5. 诺顿定理**：等效为**短路电流 i_sc 并联 R_eq**，与戴维南互为对偶。

**6. 最大功率传输**：负载 R_L = R_eq 时获得最大功率，P_max = u_oc² / (4R_eq)。

**与工作的连接**：继电保护计算"短路点等值阻抗"、变电站简化等值电路，全是戴维南思想——把电源侧看成一个"电压源+内阻"。

### 模块三 · 一般分析方法与电路定理 ★★

**一句话定位**：不化简也能算——用一套"代数方程"解出所有支路电压电流，是潮流计算等大规模求解的思想源头。

**1. 三种方法的取舍**
| 方法 | 方程个数 | 适合情况 |
|---|---|---|
| 支路电流法 | 2b（最多） | 几乎不用，只作概念 |
| 回路电流法（网孔法） | b−n+1 | 网孔数少时 |
| 节点电压法 | n−1（最少） | 节点少时，工程手算首选 |

**2. 节点电压法要点 ★★**
- 选参考节点（地），对其余 n−1 个节点列方程；
- 自导（本节点相连导纳之和）为正，互导（两节点公共导纳）为负；
- 电流源注入本节点取正，流出取负；
- 含理想电压源时把它跨接的两个节点看作"超级节点"处理。

**3. 叠加定理 ★★**
- 独立源逐个单独作用（不作用的电压源短路、电流源开路），**受控源始终保留**；
- 各分响应（电压/电流）代数和 = 总响应；
- **易错点：功率不能叠加**（P 与 U、I 的平方有关），必须先算总 U、I 再算功率。

**与后续课程的连接**：电力系统潮流计算 = 大规模节点电压法（几十万节点），本模块是理解潮流计算的思维入口。

### 模块四 · 动态电路暂态分析（三要素法）★★★

**一句话定位**：电路从"开关动作"到"重新稳定"的过渡过程，用"三要素"一网打尽——短路暂态、励磁涌流衰减全是这个模型。

**1. 储能元件（换路定律的基础）**
- 电容：i = C·du/dt，**电压不能突变** → u_C(0⁺) = u_C(0⁻)；储能 W = ½Cu²；
- 电感：u = L·di/dt，**电流不能突变** → i_L(0⁺) = i_L(0⁻)；储能 W = ½Li²；
- 记忆：电容像"电压惯性"，电感像"电流惯性"。

**2. 换路瞬间的等效电路**
- 0⁺ 时刻：电容 → 电压源（值 u_C(0⁺)）；电感 → 电流源（值 i_L(0⁺)）；
- 用它求出各量的初始值 f(0⁺)。

**3. 一阶电路三要素法 ★★★（本模块核心）**

```
f(t) = f(∞) + [f(0⁺) − f(∞)] · e^(−t/τ)
```

三个要素：
- **初值 f(0⁺)**：由换路定律 + 0⁺等效电路求；
- **稳态值 f(∞)**：t → ∞ 时直流稳态，**电容开路、电感短路**后求；
- **时间常数 τ**：τ = R_eq·C（电容）或 L/R_eq（电感）；R_eq 是从储能元件两端看入、独立源置零后的等效电阻。

<ThreeElement />

**4. 时间常数的意义**：τ 越大过渡越慢；t = τ 时过渡完成 63.2%，t = 3τ ~ 5τ 时基本稳定（工程上认为过渡结束）。

**5. 三种响应**：零输入响应（衰减到 0）、零状态响应（从 0 上升）、全响应 = 稳态分量 + 暂态分量。

**6. 二阶电路（了解）**：RLC 串联出现过阻尼、临界、欠阻尼（衰减振荡）三种情况，记住"欠阻尼会振荡"这个概念即可，推导不用深究。

**与工作的连接**：短路电流中的非周期分量按指数衰减、变压器励磁涌流几个周期衰减、电容补偿装置投切涌流——都是这个模型，时间常数决定"衰减多快"。

### 模块五 · 正弦稳态电路（相量法）★★★

**一句话定位**：交流电网的全部计算语言——把微分方程变成复数的代数方程，一劳永逸。发电侧工作天天在用（电压、电流、功率、功率因数）。

**1. 正弦量与相量**
- 正弦量三要素：幅值 U_m、角频率 ω、初相 φ；
- 有效值：U = U_m / √2（市电 220V 就是有效值）；
- **相量 = 复数**（大小用有效值，角度用初相），如 Û = U∠φ；相量不是瞬时值，是"换了一种数学表示"。

<Phasor />

**2. 元件与阻抗 ★★★**
- 电阻：Û = R·İ；
- 电感：Û = jωL·İ（感抗 X_L = ωL）；
- 电容：Û = İ/(jωC)（容抗 X_C = 1/(ωC)）；
- 串联阻抗：Z = R + jX（X = X_L − X_C）；|Z| = √(R² + X²)，φ = arctan(X/R)；
- **这就是继保课里"为什么用 Z 不用 R"的由来**——交流阻碍是电阻+电抗的合成。

**3. 相量形式的 KCL/KVL**：两大定律对相量照常成立，电路分析方法（节点、回路、叠加、戴维南）全部可以直接搬到相量域。

**4. 功率与功率三角形 ★★★（工作最常用）**
| 功率 | 公式 | 单位 | 含义 |
|---|---|---|---|
| 有功 P | UI·cosφ | W | 真正做功的部分 |
| 无功 Q | UI·sinφ | var | 建立磁场/维持电压的部分 |
| 视在 S | UI | VA | 设备承受的总功率 |

- S² = P² + Q²；功率因数 cosφ = P/S；
- 提高功率因数：感性负载（电动机）**并联电容**补偿无功；
- 记忆：**MW 是你用的，Mvar 是维持电压要的，MVA 是设备扛的**（呼应变电站铭牌）。

**5. 谐振**
- 串联谐振：ω₀ = 1/√(LC)，此时阻抗最小、电流最大（电压谐振）；品质因数 Q = ω₀L/R = 1/(ω₀CR)，谐振时电感/电容上电压是电源的 Q 倍；
- 并联谐振：阻抗最大、电流最小（电流谐振），用于选频/滤波。

**与后续课程的连接**：距离保护测 Z = U/I、功率方向元件、三相短路电流计算、潮流计算，全部是相量法。

### 模块六 · 三相电路 ★★★

**一句话定位**：电网是三相的，发电、输电、配电全在三相框架下——发电侧最对口的一章。

**1. 两种接法（必背关系）**
| 接法 | 线电压与相电压 | 线电流与相电流 |
|---|---|---|
| 星形 Y | U_l = √3·U_p（线电压超前30°） | I_l = I_p |
| 三角形 Δ | U_l = U_p | I_l = √3·I_p（滞后30°） |

- 记忆口诀：**Y 升压（√3）、Δ 升流（√3）**；常见数值：相电压 220V → 线电压 380V。

**2. 对称三相电路计算**
- 对称负载（三相阻抗相同）+ 对称电源 → 三相完全独立，**化为一相计算**（Y-Y 连接中性点等电位，可直接短接）；
- 其余两相按相位差 ±120° 推出来。

**3. 三相功率 ★★★**
- 对称三相：P = √3·U_l·I_l·cosφ；Q = √3·U_l·I_l·sinφ；S = √3·U_l·I_l；
- 注意公式里的 cosφ 是**每相阻抗角**，不是"线电流与线电压夹角"；
- 三表法（三相四线）与两表法（三相三线）测功率，了解即可。

**4. 中线的作用**
- 三相四线制中，中线保证不对称负载时各相电压仍对称；
- **中线不允许装保险/开关**（断了会造成相电压失衡、烧坏单相负载）——这是现场铁规矩。

**5. 不对称与中性点位移（了解）**：负载不对称时中性点电位漂移，导致有的相过压、有的欠压——调度和运行里"三相不平衡"就是这个概念。

**与后续课程的连接**：发电机/变压器 Y-Δ 接线、并网电压匹配、三相短路电流计算、母线电压，全部是三相框架。

### 模块七 · 耦合电感与变压器 ★★

**一句话定位**：从"电路"通向"电机学"的桥——变压器、互感器（CT/PT）都是耦合电感的应用。

**1. 互感与同名端**
- 两个线圈磁耦合：u₁ = L₁·di₁/dt ± M·di₂/dt；
- 同名端：电流同时从同名端流入时互感助磁；同名端决定正负号；
- 耦合系数：k = M/√(L₁L₂)，0 ≤ k ≤ 1（k = 1 全耦合）。

**2. 理想变压器 ★★★（发电侧最常用）**
- 变比 n = N₁/N₂；
- 电压关系：u₁/u₂ = n；
- 电流关系：i₁/i₂ = 1/n（注意参考方向，副边电流与变压器相反）；
- **阻抗折算：从原边看，副边负载 Z_L 等效为 n²·Z_L**——这就是"变压器把阻抗放大 n² 倍"。

**3. 实际变压器**：= 理想变压器 + 漏阻抗 + 励磁支路 + 损耗，具体等值电路在电机学展开。

**与后续课程的连接**：电力变压器等值电路、CT/PT 变比、继保计算里"阻抗折算到统一基准"，全靠本模块。

### 模块八 · 进阶工具（了解级）★

学有余力再看，发电侧工作基本用不上，但知道"有这些东西"遇到时能查：

- **非正弦周期电流**：傅里叶分解为基波+谐波；有效值 U = √(U₀² + U₁² + U₂² + ...)；平均功率 = 各次谐波功率之和；——谐波治理的数学基础；
- **拉普拉斯变换法**：把微分方程变代数方程（s 域），动态电路通用解法；思路了解即可；
- **二端口网络**：Z/Y 参数描述"黑箱"端口关系，滤波器、放大器的分析工具；
- **网络函数与频率响应**：幅频特性、相频特性——滤波器设计的核心概念。

## 六、自测题（学完全部模块后做）

1. 6Ω 与 3Ω 两电阻并联，等效电阻是多少？
2. 电压源 12V（内阻 2Ω）外接 4Ω 负载，求负载电流和负载功率。
3. 电容 2μF 充电至 10V，储存能量是多少？
4. R = 10kΩ、C = 100μF 的一阶 RC 电路，时间常数 τ 是多少？约几倍 τ 后视为稳定？
5. 正弦电压 u = 311sin(314t + 30°) V，求有效值、频率、初相。
6. R = 3Ω、X = 4Ω 串联，端电压 100V，求阻抗模、电流、有功、无功、功率因数。
7. 对称三相负载星形连接，相电压 220V、每相电阻 10Ω（纯阻），求线电压、线电流、三相总有功功率。
8. 理想变压器变比 n = 10，副边接 4Ω 负载，从原边看等效阻抗是多少？

### 答案

1. R_eq = 6×3/(6+3) = **2Ω**
2. I = 12/(2+4) = **2A**；P = 2²×4 = **16W**
3. W = ½×2×10⁻⁶×10² = **100μJ**
4. τ = RC = 10×10³×100×10⁻⁶ = **1s**；约 3~5 倍 τ（3~5s）视为稳定
5. U = 311/√2 ≈ **220V**；f = 314/(2π) = **50Hz**；初相 **30°**
6. |Z| = √(3²+4²) = **5Ω**；I = 100/5 = **20A**；P = 100×20×cosφ = 100×20×0.6 = **1200W**；Q = 100×20×0.8 = **1600var**；cosφ = 3/5 = **0.6**
7. U_l = √3×220 ≈ **380V**；I_p = I_l = 220/10 = **22A**；P = √3×380×22×1 ≈ **14480W ≈ 14.5kW**
8. Z' = n²×4 = 10²×4 = **400Ω**
